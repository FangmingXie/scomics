# Cross-species IT axis matching by CCA on ortholog loadings (scripts 16, 17)

Implements `plan/it_evo/03.crossspecies_axis_matching_cca.md`. Which mouse IT axis best matches
which human IT axis, where an axis is a linear mixture of varimax (VX) components and matching is
correlation of orthologous-gene loadings. The estimator is closed-form CCA = cosines of the
principal angles between the two gene-loading subspaces (singular values of `Qxᵀ Qy` on
orthonormalized, centered blocks); `scipy.linalg.subspace_angles` agrees to machine precision.

## Scripts

- `scripts/it_evo/16.crossspecies_axis_matching.py` — closed-form CCA spectrum, subspace overlap
  Σcos²θ, module-blocked + random cross-validation, gene bootstrap weight stability, per-component
  permutation null, Gate-A sensitivity, pairwise Pearson baseline, top genes, and the 16-cell
  specificity grid. `--tokens` subsets the diagonal detail; `--no-grid` skips the grid; `--compat`
  runs the L2/3 plumbing control on the old `l23_evo/05+18` inputs.
- `scripts/it_evo/17.viz.crossspecies_axis_matching.py` — per-token 4-panel HTML (spectrum with
  null band + CV + z, Σcos²θ panel, pairwise heatmap, leading-pair gene scatter) and the
  six-panel specificity grid with the diagonal outlined.

Run: `conda run --no-capture-output -n archetype python -u scripts/it_evo/16.crossspecies_axis_matching.py`
then `... 17.viz.crossspecies_axis_matching.py` (~24 s + a few s).

## Result

**L2/3 has a genuine conserved axis; L4/L5IT/L6IT have real subspace overlap but no identifiable axis.**

| token | n | CCA1 (z) | Σcos²θ frac (z) | comp-1 blocked CV | Σcos²θ blocked-CV excess | boot median \|cos\| |
|---|---|---|---|---|---|---|
| L23  | 357 | 0.623 (13.0) | 0.132 (28.0) | 0.53 | 0.615 | 0.94 → **stable** |
| L4   | 479 | 0.365 (7.0)  | 0.067 (14.4) | 0.15 | 0.407 | 0.80 → unstable |
| L5IT | 332 | 0.334 (4.1)  | 0.050 (8.0)  | 0.06 | 0.326 | 0.70 → unstable |
| L6IT | 313 | 0.381 (5.7)  | 0.067 (11.5) | 0.11 | 0.351 | 0.79 → unstable |

- **L2/3**: CCA1 0.623 stands clear of CCA2 0.488, weights are essentially "human VX2 vs a mouse
  VX1/VX8 mixture" (VX2 weight 0.96, bootstrap median 0.94), gene-localized to the
  deep↔superficial gradient (RORB, GRM1, TRHDE, EPHA6, DSCAML1, PTPRT — matches `l23_evo/24`),
  and the only diagonal-dominant row in every grid.
- **L4/L5IT/L6IT**: Σcos²θ 0.25–0.27 sits far above nulls of 0.05–0.08 (subspaces genuinely
  non-independent), but the overlap is spread across two–three components of comparable z (L4
  peaks at component 3, L5IT/L6IT at component 2), component-wise CV collapses (0.06–0.15), and
  bootstrap weights are unstable. Honest claim: *"these subspaces share structure,"* **not**
  *"human axis X ↔ mouse axis Y."* Where they match anything by z it is **mouse L5IT** (human
  L4 → mouse L5IT, human L6IT → mouse L5IT), consistent with one pan-IT gradient rather than
  subclass-specific correspondence.

The component-wise vs subspace-level dissociation is why both statistics are first-class:
"fails cross-validation" is true of the component-wise statistic and false of the subspace one.
The subspace CV figure is reported as the **excess over the permuted-pairing null** (raw held-out
Σcos²θ carries a random-subspace baseline ≈ r²/n_test); this excess returns ≈0 under destroyed
pairing (positive control) while random-fold CV stays inflated — the co-expression leakage the
module blocking corrects.

## Second axis of L2/3 (CCA2): a stable 2D subspace, not a second pinned axis

L2/3 is the one subclass where a *second* conserved dimension has support. Unlike the second
components of L4/L5IT/L6IT, L2/3's CCA2 **cross-validates**:

- **r = 0.488**, clear of CCA3 (0.304); **z = 13.0** — as high as CCA1.
- **blocked-CV = 0.426** (random 0.405) with **all five folds positive** (0.564, 0.511, 0.331,
  0.304, 0.448). The non-L2/3 second components collapse here (folds go negative); L2/3's does not.
- CCA1² + CCA2² = 0.63, i.e. **79% of the total Σcos²θ (0.789)** — the conserved overlap is
  essentially 2-dimensional, not carried by CCA1 alone.

But its *weight vector* is only borderline reproducible, so the script flags it `stable=False`:
bootstrap median |cos| ≈ 0.904 (human) / 0.900 (mouse), with ~50% of resamples below 0.9 and 5th
percentiles ≈ 0.52. Much of this is CCA1↔CCA2 rotational trade-off (they are close, 0.62 vs 0.49):
the **2D span {CCA1, CCA2} is more stable** (bootstrap overlap median 0.91 human / 0.92 mouse,
p5 ≈ 0.76) than the isolated second axis. So the honest statement is a stable **2D conserved
subspace**, with CCA1 sharply identified and the second dimension real-but-not-orientation-pinned.

CCA2's gene program is distinct from CCA1's deep↔superficial gradient — top genes by
|x·y| loading are `SORCS3, KCNH7, SGCZ, CDH20, GPC6, PLCB4, DGKG, DCC, KCNIP3, KCNH5…` (channels /
adhesion / axon-guidance), so it is not a reshuffle of CCA1. (The script withholds CCA2 from
`16.L23_axis_cca_top_genes.tsv`, which gates top genes to bootstrap-stable pairs; the list here is
a caveated follow-up.)

### CCA2 in the VX and PC bases

Applying the `plan/it_evo/04` re-expression (PCA on the cell-level Gate-A VX coordinates keeping
all `k` components — an orthogonal rotation, so the spectrum is unchanged and `a_pc = comps · a_vx`,
verified `np.allclose` to 1e-9), the second axis reads:

| side | VX basis | PC basis (var ratio) |
|---|---|---|
| human | VX9 +0.67, VX10 +0.52, VX8 +0.47, VX7 +0.14, VX6 +0.12, VX2 −0.10 | **PC6 −0.57, PC4 +0.52, PC3 +0.52**, PC1 −0.31, PC2 −0.17, PC5 −0.05 |
| mouse | VX7 −0.81, VX9 +0.40, VX5 +0.27, VX8 +0.23, VX2 −0.22, VX1 +0.05 | **PC2 −0.72**, PC4 +0.46, PC5 +0.37, PC3 −0.36, PC1 +0.06 |

The PC view explains the borderline stability. Where **CCA1 is human PC1** (the 52%-variance
dominant gradient), **CCA2 rides human's low-variance PCs — PC6 (5%), PC4 (7%), PC3 (13%)** — with
PC1 contributing only −0.31. A conserved direction living in the low-variance tail is intrinsically
noisier to estimate from finite genes, which is exactly the CCA1-stable / CCA2-borderline pattern
the bootstrap shows. On the mouse side CCA2 concentrates on PC2 (−0.72, the second-variance
direction). Basis change does not make an unstable direction stable — it just localizes *why*
CCA2 is harder: it is a low-variance, multi-PC direction on the human side.

## Verification (all pass)

1. **Pilot reproduction** — diagonal spectra, per-component z (L23 13.0/13.0/8.2/7.6/5.0/−1.0),
   Σcos²θ, the full 16-cell CCA1/z grid, random-fold CV means, and bootstrap medians all return
   within Monte-Carlo noise.
2. **CV positive control** — destroy the pairing → blocked component-wise and Σcos²θ-excess CV
   both → ≈0 (L23 0.53→−0.01; L5IT averaged −0.03±0.07 over 20 permutations). Random-fold
   subspace CV stays above blocked on real data (leakage).
3. **Σcos²θ identity** — `Σsᵢ² == ‖Qxᵀ Qy‖²_F == trace(Qxᵀ Qy Qyᵀ Qx)` to 1e-6; permutation null
   mean matches `kx·ky/(n−1)` (0.050–0.101 vs predicted 0.050–0.101).
4. **L2/3 compat** — old `05+18` inputs, 521 shared orthologs, spectrum
   `0.5981 0.4111 0.3412 0.2212 0.1680 0.0390`, matching `23/24` exactly (the it_evo record gives
   357 orthologs / 0.623, not 521 / 0.598, because `it/19` and `l23_evo/18` select different HVGs).
5. **Invariance** — the spectrum is unchanged under column z-scoring and under a random invertible
   mixing of either block, and equals `cos(subspace_angles)` (the regression test the design rests on).
6. **Gate monotonicity** — all-10-VX spectrum dominates Gate-A element-wise and carries higher z
   (L23 CCA1 0.756/z16.8 vs 0.623/z13.3); dropping human VX2 collapses L23 CCA1 to 0.49, dropping
   VX6 barely moves it — VX2 is the axis, as the weights say.
7. **z caveat** — z is a bounded-support standardized effect size, not a normal deviate; the null
   is right-skewed with a short right tail (largest draw ≈ z4.4 over 20k perms), so every grid cell
   sits at the empirical p floor and the BH-q grid is uniformly at 1/(N+1) — significance is real
   but the p-value is not Gaussian-interpretable. CV, not the permutation null, is the load-bearing test.
