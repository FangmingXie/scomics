# VX3-Binned NR vs DR DEG Analysis — Pseudobulk + simple tests (v3) — Cheng22 Astrocytes

**Dataset:** Cheng et al. 2022 mouse scRNA-seq (`cheng22_astro.h5ad`)
**Cell populations:** NR (P28 + P38, 3,144 cells) and DR (P28_dr + P38_dr, 4,044 cells)
**Replication:** 7 NR mice, 8 DR mice
**Scripts:** 44 · 45.v3 (`45.v3.deg_vx3_bins_nr_vs_dr_pseudobulk.py`)
**Context in the series:** follows v1 (cell-level LMM) and v2 (hardened LMM); a lightweight, dependency-free bridge to the calibrated v4 (pseudobulk + DESeq2).

---

## Context

VX3 is the third varimax component of the NR Arch1+Arch2 embedding; DR cells are projected into it (script 44). Cells are split into 4 equal-size VX3 bins (within each sample) to test whether the NR-vs-DR (visual-experience) response is spatially graded along VX3.

v2 established that the cell-level LMM was **numerically failing** in bins 1–3 (~78% of genes hit a statsmodels variance-boundary degeneracy, SE ≈ 10⁶), collapsing them to 4–7 DEGs — an artifact, since effect size, cell count, and between-mouse ICC (≈0.016) are matched across all four bins. v3 tests that diagnosis with the simplest possible fix that has no per-gene random-effect to break: **pseudobulk**.

This is a **prototype**. No DESeq2 / edgeR / rpy2 / R were available in the env, so it uses two simple, dependency-free tests; the calibrated version is **v4 (pseudobulk + DESeq2)**, which should be preferred for any reported result.

---

## Procedures

### Pseudobulk + simple two-group tests (script 45.v3)
- Binning identical to scripts 45 / 45.v2 (4 equal-size VX3 quantile bins within each sample).
- **Pseudobulk:** sum raw counts across cells for each (sample × bin) → one profile per mouse per bin; drop a profile with < 10 cells (none dropped). Per bin: **7 NR vs 8 DR** pseudobulk samples — the mouse is the unit of replication.
- Normalization: CPM per pseudobulk sample, then `log2(CPM + 1)`.
- Gene filter: detected (count > 0) in ≥ 50% of samples in **both** groups (~12.7k of 16.6k genes kept).
- Per gene, two two-group tests (vectorized, DR vs NR):
  - **Welch's t-test** (unequal variance) → `pval_t` / `fdr_t` — **primary**.
  - **Mann-Whitney U / Wilcoxon rank-sum** → `pval_w` / `fdr_w` — robustness check.
- `log2FC` = mean(log2CPM_DR) − mean(log2CPM_NR) (positive = up in DR).
- FDR: Benjamini-Hochberg per bin per test. Significance (called on the t-test): `fdr_t` < 0.05 **and |log2FC| > log2(1.5) ≈ 0.585**.
- Output columns: `gene, log2FC, mean_NR, mean_DR, pval_t, fdr_t, pval_w, fdr_w, n_NR, n_DR`.

**This confirms the v2 diagnosis.** Bins 1–3 — collapsed to 4–7 DEGs by the cell-level LMM — now yield **140–174 DEGs**, the same order of magnitude as bin 4 (299). The bins were never statistically different; the mixed-model degeneracy was. All bins are **DR-skewed** (~65–67% up in DR). Bin 4 is still the strongest, but no longer uniquely so.

A shared core of **25 genes** is significant in all four bins (union across bins: 495).

## Two caveats that motivate v4

1. **Wilcoxon has essentially zero power here — do not use it.** With n = 7 vs 8, the smallest possible two-sided Mann-Whitney p-value is 2 / C(15,7) ≈ 1.4×10⁻³ (observed exactly as `min pval_w` in every bin). After BH over ~12.7k genes, the best achievable `fdr_w` is ~0.07–0.13, so **nothing** clears 0.05. Rank tests are underpowered at this replicate count.

2. **The unmoderated Welch t-test is anticonservative.** At n = 7/8 a gene with a spuriously small sample variance gets an inflated t-statistic and an over-optimistic p-value. DESeq2/limma exist precisely to **moderate per-gene variance/dispersion across genes**. So the 140–299 counts are an upper-ish estimate; the truth lies between the t-test (too liberal) and Wilcoxon (too conservative).

→ **v4 (pseudobulk + DESeq2)** resolves both: dispersion shrinkage gives calibrated FDR at low replicate count, and apeglm shrinks noisy LFCs. Use v4 for any reported result; v3 is the transparent, dependency-free sanity check that pseudobulk fixes the v2 bin collapse.

---

## Conclusions

- **The v2 bin-1–3 collapse was a numerical artifact, not biology** — pseudobulk recovers 140–174 DEGs in those bins, comparable to bin 4.
- **The NR-vs-DR response is broad across VX3 and DR-skewed**, with recurring up-in-DR (Eprs, Nr4a1/2/3, Adamts9) and up-in-NR (Hmgn3, Wwc1, Celrr) genes.
- **Rfx4 is up in DR in all bins** (significant in 2–4), consistent with the raw data.
- **Choose the test deliberately at n=7/8:** Wilcoxon underpowered, Welch t-test anticonservative — both bracket the answer; DESeq2 (v4) is the calibrated middle.
