# Two-dataset Harmony archetype analysis — L4 IT (cheng22 + yoo25, gao25 dropped)

## Goal

Repeat the tri-dataset Harmony L4 archetype pipeline (script set `32`, see
`report/it/32.harmony.three_L4_archetype.md`) **with gao25 removed entirely** — only
cheng22 (P28NR) and yoo25 (P21) — to test how much the archetype structure depends on
the gao25 (DevVIS P56) data.

## Pipeline (scripts under `scripts/it/`)

Identical structure to set `32`, gao25 dropped:

1. **`33.harmony.two_L4_embed.py`** — load + merge cheng22 + yoo25 + Harmony embedding.
2. **`33.harmony.two_L4_num_archetype.py`** — archetype NOC sweep (tqdm + unbuffered
   tee-logging to `local_data/log/it/`).
3. **`33.harmony.viz.two_L4_num_archetype.py`** — metrics + interactive HTML.

### Setup (unchanged from `32` except gao25 removal)
- L4 only; shared genes = inner join of cheng22 ∩ yoo25 (identical 16,572-gene var),
  mito removed.
- Counts from `.raw`; depth from each dataset's validated column (cheng22 `n_counts`,
  yoo25 `total_counts`).
- Harmony batch = `dataset:sample` (6 groups: 4 cheng22 + 2 yoo25).
- Archetype space = top 5 Harmony PCs; PCHA NOC sweep 2–6; `NREPEATS=10`, `N_OUTER=3`.
- **Merged object: 6,905 cells** (cheng22 4,732 + yoo25 2,173). Harmony converged in 9 iters.

## gao25-anchoring note (key finding)

Direct contrast with the tri-dataset run (`32`):

| | NOC=3 ARV | NOC=3 ARV_std | stable NOC |
|---|---:|---:|---|
| **3 datasets** (`32`, +gao25) | 0.033 | 0.006 | **3** (clean) |
| **2 datasets** (`33`, −gao25) | 0.196 | 0.138 | **2** (3rd shaky) |

- **With gao25**, NOC=3 was unambiguous: effEV peaked at 3, ARV tiny (0.033), narrow band.
- **Without gao25**, only NOC=2 is clearly stable (ARV ≈ 0.01). At NOC=3, effEV still
  peaks (0.514) but ARV jumps to ~0.196 with a **large error bar (±0.138)** — the 3rd
  archetype wobbles ~20% of the inter-archetype distance and the estimate is poorly
  converged, i.e. borderline rather than robust.

**Interpretation:** gao25's cells — specifically its `L4/5 IT CTX Glut` cluster, which
carries L5-leaning cells mapped into L4 — appear to **anchor the 3rd archetype**.
Removing them collapses the joint manifold to 2 solid archetypes plus a shaky 3rd.

**Methodological aside (consistent with the `32` discussion):** this is exactly the
case the ARV error bar is useful for as a Monte-Carlo / convergence diagnostic — at
NOC=3 the band (±0.138) is *not* small relative to the signal, correctly flagging the
model-selection call as genuinely uncertain rather than just a different point estimate.
The 3rd archetype's existence is data-dependent (driven by gao25), not a stable property
of cheng22+yoo25 alone.
