# Plan: First-Pass Analysis of Jorstad23 Human L2/3 IT snRNA-seq

## Context
First exploratory analysis of the Jorstad et al. 2023 human primary visual cortex (V1) L2/3 IT neuron dataset. The goal is to characterize cell type diversity across 6 pre-annotated clusters, compute standard dimensionality reduction outputs, and disentangle biological cell identity variation from technical/sample-to-sample variation across 3 donors, 2 labs, and 3 ages.

**Key data facts:**
- File: `links/l23_evo/jorstad23_human_WithinArea_L23IT.h5ad`
- 47,125 cells × 29,352 genes
- `adata.X`: already log-normalized (float32, values ~2–12) — skip CP10k/log1p step
- 6 clusters: `WithinArea_cluster` = L2/3 IT_1 through L2/3 IT_6
- Sample covariates: `donor_id` (3), `Source` (2 labs), `development_stage` (3 ages, confounded with donor — same info)

## Script 1: `scripts/l23_evo/01.compute_jorstad23.py`  *(all computation)*

### File paths / config (top of script)
```python
PROJECT_ROOT   = os.path.dirname(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
INPUT_FILE     = os.path.join(PROJECT_ROOT, 'links', 'l23_evo', 'jorstad23_human_WithinArea_L23IT.h5ad')
OUT_RES_DIR    = os.path.join(PROJECT_ROOT, 'local_data', 'res', 'l23_evo')
OUT_PCA        = os.path.join(OUT_RES_DIR, '01.pca_coords.tsv')
OUT_UMAP       = os.path.join(OUT_RES_DIR, '01.umap_coords.tsv')
OUT_PC_CORR    = os.path.join(OUT_RES_DIR, '01.pc_covariate_corr.tsv')
OUT_MARKERS    = os.path.join(OUT_RES_DIR, '01.markers.tsv')

N_HVG          = 2000
N_PCS          = 10
N_NEIGHBORS    = 15
N_PCS_FOR_CORR = 10
MIN_LOG2FC     = 0.5
MIN_FRAC_IN    = 0.25
CLUSTER_COL    = 'WithinArea_cluster'
COVARIATE_COLS = ['donor_id', 'Source']
METADATA_COLS  = [CLUSTER_COL] + COVARIATE_COLS + ['development_stage', 'nCount_RNA']
```

### Part A — HVG + PCA + UMAP
```
X_norm = adata.X.toarray()  (already log-normalized)
HVG by variance (top N_HVG) →
StandardScaler.fit_transform →
PCA(N_PCS, random_state=0) →
umap.UMAP(n_neighbors=N_NEIGHBORS, random_state=0) on top PCs →
Save: OUT_PCA (PC1–10 + metadata cols), OUT_UMAP (UMAP1–2 + metadata cols)
```

### Part B — PC-covariate correlations
```
One-hot encode: WithinArea_cluster (6 cols) + donor_id (3 cols) + Source (2 cols)
  — development_stage excluded: each donor has a unique age, so it's redundant with donor_id
Pearson correlation between PC1–N_PCS_FOR_CORR and each one-hot column
Save: OUT_PC_CORR  (rows=PCs, cols=cell-type + covariate dummies)
```

### Part C — Marker genes (Wilcoxon one-vs-rest)
```
For each cluster c in CLUSTER_COL:
  cells_in = cluster == c;  cells_out = ~cells_in
  For each HVG gene g:
    scipy.stats.ranksums(X_norm[cells_in, g], X_norm[cells_out, g]) → pval
    log2FC = (mean(cells_in) - mean(cells_out)) / log(2)
    frac_in / frac_out = fraction of cells with expression > 0
  BH FDR: statsmodels.stats.multitest.multipletests
  Filter: log2FC >= MIN_LOG2FC and frac_in >= MIN_FRAC_IN
Save: OUT_MARKERS (gene, cluster, log2FC, pval, fdr, frac_in, frac_out), sorted by cluster then fdr
```

## Script 3: `scripts/l23_evo/03.variance_partition_jorstad23.py`

Reads `01.pca_coords.tsv`. For each PC, computes partial R² for each factor by fitting the full OLS model and comparing to the model with that factor dropped.

**Factors:** `cell_type` (one-hot, 6 cols), `donor` (one-hot, 3 cols), `source` (one-hot, 2 cols), `library_size` (nCount_RNA, z-scored continuous).

**Key finding:** PC1 is dominated by library size (57%), not biology. PC3 and PC5 are the cleanest cell-type axes.

## Script 4: `scripts/l23_evo/04.viz_pcs_jorstad23.py`

Reads `01.pca_coords.tsv`. Plots PC1, PC3, PC5 (the cell-type-robust axes) using `scatter_categorical_html` with 3×2D panels + 3D panel and toggle buttons for cluster/donor/source/age coloring.
