# Plan: Archetype Score Script (modified script 20) for Cheng22 Mouse L2/3 IT

## Context

Script 20 runs one-vs-rest Wilcoxon to find per-archetype marker genes. The user wants a new script (`21`) that:
1. Replaces the one-vs-rest test with a **conservative one-vs-each-other-archetype** Wilcoxon — for every gene, run separate tests against each other archetype, then keep the **max p-value** and **min log2FC** (worst-case across pairwise comparisons). A gene survives only if it consistently outperforms all other archetypes.
2. Uses those unbiased markers to compute a per-cell **archetype score**: normalize each marker gene's expression to [0,1] across cells (2nd–98th percentile clip), then average across genes.
3. Visualizes the scores on the PCHA scatter.

### Key modification: conservative one-vs-each Wilcoxon

For each archetype k, compare its 300 cells against the 300 cells of **each other archetype j** separately. Per gene, keep the result that is hardest to pass — max p-value and min log2FC across the (NOC−1) pairwise tests. FDR correction is applied to the resulting conservative p-values.

```python
for k in range(NOC):
    in_idx  = top_cells[k]
    X_in    = X_norm[in_idx]
    frac_in = (X_in > 0).mean(axis=0)

    log2fc_mat = []   # shape: (NOC-1, n_hvg)
    pval_mat   = []
    frac_out_list = []

    for j in range(NOC):
        if j == k:
            continue
        X_out = X_norm[top_cells[j]]
        log2fc_j = (X_in.mean(axis=0) - X_out.mean(axis=0)) / np.log(2)
        pvals_j  = np.array([scipy.stats.ranksums(X_in[:, g], X_out[:, g])[1]
                              for g in range(n_hvg)])
        log2fc_mat.append(log2fc_j)
        pval_mat.append(pvals_j)
        frac_out_list.append((X_out > 0).mean(axis=0))

    # conservative: worst case across all pairwise comparisons
    log2fc   = np.stack(log2fc_mat).min(axis=0)    # smallest fold-change
    pvals    = np.stack(pval_mat).max(axis=0)      # largest p-value
    frac_out = np.stack(frac_out_list).mean(axis=0) # avg frac across other archetypes

    _, fdr, _, _ = multipletests(pvals, method='fdr_bh')
    # filter by frac_in >= FRAC_IN_THRESH and fdr < FDR_THRESH
    # sort by conservative log2FC descending — same thresholds as script 20
```

### Archetype score computation

After `markers_df` is assembled:

```python
scores = np.zeros((n_cells, NOC), dtype=np.float32)

for k, name in enumerate(ARCHETYPE_NAMES):
    top_genes = (markers_df[markers_df['archetype'] == f'archetype_{k+1}']
                 .head(N_SCORE_GENES)['gene'].values)
    cols = [np.where(hvg_names == g)[0][0] for g in top_genes if g in hvg_names]
    if not cols:
        continue
    mat  = X_norm[:, cols]                              # (n_cells, n_genes)
    lo   = np.percentile(mat, SCORE_PCTILE_LO, axis=0) # per-gene 2nd pctile
    hi   = np.percentile(mat, SCORE_PCTILE_HI, axis=0) # per-gene 98th pctile
    rng  = np.where(hi > lo, hi - lo, 1.0)             # avoid div-by-zero
    mat_norm      = np.clip((mat - lo) / rng, 0, 1)    # [0,1] per gene
    scores[:, k]  = mat_norm.mean(axis=1)

scores_df = pd.DataFrame(scores, index=cell_barcodes,
                          columns=[f'score_{n}' for n in ARCHETYPE_NAMES])
scores_df.to_csv(OUT_SCORES, sep='\t')
```
