# OrthoAxis: Cross-Species VX Subspace Matching (Cheng22 ↔ Jorstad23)

## Context

The existing pipeline applies varimax rotation to PCA separately for human L2/3 IT (Jorstad23, 47k cells) and mouse L2/3 IT (Cheng22, 4k cells), producing cell-type-informative VX components in each species independently. Prior cross-species work (scripts 12–16) maps **mouse cells into human space**. The new OrthoAxis analysis instead compares the **VX subspace structures themselves** — asking which axes in human correspond to which axes in mouse, using shared orthologous gene loadings as the common reference.

Two parallel approaches:
- **Script 23**: simple Pearson correlation matrix of VX loading vectors in shared ortholog space
- **Script 24**: CCA between human and mouse VX loading matrices in shared ortholog space

## Script 23 — `scripts/l23_evo/23.orthoaxis_corr.py`

**Approach**: For each pair (human VXi, mouse VXj), compute Pearson correlation of their gene loading vectors restricted to shared ortholog genes.

**Steps:**
1. Load loadings + variance partition for both species; select cell-type-informative VX columns
2. Load ortholog table; keep 1-to-1 pairs; restrict loadings to shared genes (human gene name matched to mouse gene name via orthologs)
3. Compute `(n_human_vx × n_mouse_vx)` Pearson correlation matrix of loading vectors
4. Output correlation TSV + Plotly heatmap HTML (annotated with values)
5. For each human VX, identify best-matched mouse VX; output top-N shared ortholog genes (ranked by product of |loading_human| × |loading_mouse|) as a TSV
6. Cell scatter: for each top-k matched pairs, scatter human cell VX scores vs mouse cell VX scores on the same axis range (z-score normalized), colored by cell type, as a Plotly HTML

**Outputs:**
- `local_data/res/l23_evo/23.orthoaxis_corr_matrix.tsv`
- `local_data/fig/l23_evo/23.orthoaxis_corr_heatmap.html`
- `local_data/res/l23_evo/23.orthoaxis_top_genes.tsv`
- `local_data/fig/l23_evo/23.orthoaxis_cell_scatter.html`

## Script 24 — `scripts/l23_evo/24.orthoaxis_cca.py`

**Approach**: CCA between human and mouse VX loading matrices in shared ortholog gene space. Genes are "samples"; VX component scores are "features". CCA finds linear combinations of human VX components and mouse VX components that are maximally correlated.

**Steps:**
1–2: Same gene filtering as script 23
3. Build matrices X (n_shared_genes × n_human_vx) and Y (n_shared_genes × n_mouse_vx) — both z-score normalized per column
4. Fit `sklearn.cross_decomposition.CCA(n_components=min(n_human_vx, n_mouse_vx))`
5. Record canonical correlations (`np.corrcoef` of `cca.x_scores_` and `cca.y_scores_` diagonals)
6. Back-project to gene space: `human_gene_cca = X @ cca.x_weights_`, `mouse_gene_cca = Y @ cca.y_weights_`; output top ortholog genes per CCA axis
7. Project **cells** onto CCA axes:
   - Human cells: `human_vx_matrix[:, human_vx_cols] @ cca.x_weights_`
   - Mouse cells: `mouse_vx_matrix[:, mouse_vx_cols] @ cca.y_weights_`
8. Joint scatter HTML (CCA1 vs CCA2): both species overlaid, colored by species (shape) + cell type (color); include canonical correlation values in axis labels

**Outputs:**
- `local_data/res/l23_evo/24.orthoaxis_cca_correlations.tsv` (canonical correlation per CCA dim)
- `local_data/res/l23_evo/24.orthoaxis_cca_weights_human.tsv` (human VX weights per CCA dim)
- `local_data/res/l23_evo/24.orthoaxis_cca_weights_mouse.tsv` (mouse VX weights per CCA dim)
- `local_data/res/l23_evo/24.orthoaxis_cca_top_genes.tsv` (top shared genes per CCA axis)
- `local_data/fig/l23_evo/24.orthoaxis_cca_cell_scatter.html`

## Key implementation notes

- **Ortholog matching**: human loadings index is gene name (`feature_name`); mouse loadings index is mouse gene name — join via `data/human_mouse_orthologs.tsv` columns (same as script 12 does it)
- **Loading normalization**: z-score each VX loading vector over the shared gene set before correlation / CCA to make scales comparable
- **CCA regularization**: if n_shared_genes is close to n_vx_components, use `max_iter=1000`; sklearn CCA handles this via SVD internally
- **VX component selection**: hardcode as `HUMAN_VX_COLS` and `MOUSE_VX_COLS` at top of each script, derived from thresholding variance partition at `CELL_TYPE_R2_THRESHOLD`
