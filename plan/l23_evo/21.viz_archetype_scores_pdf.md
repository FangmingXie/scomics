# Plan: Redo script 21 archetype-score visualization as a vector PDF (matplotlib)

## Context

`scripts/l23_evo/21.mouse_cheng22_archetype_scores.py` currently renders the per-cell
archetype scores as an **interactive plotly HTML** (`gene_expr_scatter_html`,
`21.mouse_archetype_scores.html`) across PC1–PC2 / PC1–PC3 / PC2–PC3 panels plus a 3D
view, switchable by dropdown.

The user wants a **static, publication-ready figure** instead: a matplotlib scatter with
`rasterized=True` points (so the dense point cloud stays lightweight) saved as a
**vectorized PDF** (axes, ticks, text, archetype overlay remain true vector). It should
show **only the three scores A, B, C — one per panel — on PC1 vs PC2 only** (no PC3, no 3D).

Visual choices (confirmed): colormap **RdBu_r**, per-panel color scale at the
**5th–95th percentile** of each score — both matching the existing HTML.

Reuse decision: the expensive work (one-vs-each Wilcoxon, h5ad load, PCHA fit) is already
done and persisted. The three cached TSVs are present and **index-aligned** (verified:
4044 cells, identical same-order index):
- `local_data/res/l23_evo/21.mouse_archetype_scores.tsv` — `score_A, score_B, score_C`
- `local_data/res/l23_evo/21.mouse_pcha_xp.tsv` — `PC1…PC5` per cell
- `local_data/res/l23_evo/21.mouse_pcha_aa.tsv` — 3 archetypes × `PC1…PC5`

So we add a **viz-only script that reads these TSVs** (no recompute), following the
established `*.viz.*`-from-cache convention (e.g. `scripts/it/08.viz...`, `19.viz`, `08.refine.viz`).
The original `21.*.py` is left untouched (it still produces the compute outputs + HTML).

## Changes

### 1. `scripts/viz.py` — new reusable matplotlib helper
Add `save_score_scatter_pdf(xp, scores, names, aa, title, out_path, cmap='RdBu_r', pctile=(5,95), s=3, dpi=300)`:
- One figure, `1 × len(names)` subplots; each panel = scatter of `xp[:,0]` (PC1) vs
  `xp[:,1]` (PC2) colored by `scores[:,k]`, `cmap=cmap`, `vmin/vmax` at the per-panel
  `pctile` of that score, `s=s, rasterized=True` (points rasterized; everything else vector).
- Overlay archetypes per panel as black diamonds at `aa[:,0]/aa[:,1]` plus a closing
  polygon — mirror the logic in `_add_archetype_2d` (`viz.py:51`) but in matplotlib
  (drawn as vector, not rasterized).
- Per-panel colorbar labeled `archetype score [0–1]`; `set_xlabel('PC1')`,
  `set_ylabel('PC2')`, panel title `Score {name}`; `sns.despine`.
- Set `plt.rcParams['pdf.fonttype'] = 42` (editable vector text in Illustrator) and
  `savefig(out_path, bbox_inches='tight', dpi=dpi)` to a `.pdf`. `dpi` controls only the
  rasterized point layer's resolution.
- Reusable by the sibling score-scatter scripts (astro / cux2cre / human 25) later.

### 2. `scripts/l23_evo/21.viz.mouse_cheng22_archetype_scores.py` (NEW, thin)
- Read the three cached TSVs above (`index_col=0`); reindex `scores` to `xp.index` defensively.
- `ARCHETYPE_NAMES = ['A','B','C']`; build `scores` array from `score_A/B/C`,
  `xp` from `PC1/PC2` (only PC1–PC2 needed), `aa` from the archetype TSV's `PC1/PC2`.
- Call `save_score_scatter_pdf(...)` → `local_data/fig/l23_evo/21.mouse_archetype_scores.pdf`.
- Define all paths as capitalized constants at the top (per CLAUDE.md).
