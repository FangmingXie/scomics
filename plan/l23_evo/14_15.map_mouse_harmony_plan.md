# Plan: Mouse L2/3 archetypes + Harmony joint embedding (scripts 14 + 15)

## Context

Scripts 12 and 13 both failed to map mouse L2/3 IT cells into the human archetype space:
- Script 12 (cosine neighbors in 188-gene space): 50% of neighbor slots filled by 73 hub human cells — mouse manifold collapsed
- Script 13 (direct PCA projection): mouse cells compressed into one corner of human space (~13–33% spread ratio), offset from human cloud

Both failures share the same root cause: the gene space is dominated by the **species mean shift** rather than **within-species subtype variation**. The fix is to construct a gene space specifically from genes that drive subtype variation in both species independently, then use Harmony to remove the residual species offset before neighbor assignment.

**Two new scripts:**
- **Script 14**: Mouse-only varimax + PCHA (NOC=3) — mirrors human pipeline in scripts 01/05/09, produces mouse subtype-variation genes and archetype structure
- **Script 15**: Joint Harmony embedding + mouse-to-human assignment — builds shared subtype-variation gene space, aligns species with Harmony, assigns mouse cells to human PCHA coords via neighbors in Harmony space

## Script 14: `scripts/l23_evo/14.mouse_archetypes_yoo25.py`

### Purpose
Characterize within-mouse L2/3 IT subtype variation to identify mouse subtype-informative genes. Mirrors the human pipeline (scripts 01 + 05 + 09) applied to mouse.

### Inputs
| Variable | Path |
|---|---|
| `INPUT_MOUSE` | `links/l23_evo/yoo25_mouse_IT_P21.h5ad` |

### Outputs
| Variable | Path |
|---|---|
| `OUT_VX_COORDS` | `local_data/res/l23_evo/14.mouse_varimax_coords.tsv` |
| `OUT_VX_LOADINGS` | `local_data/res/l23_evo/14.mouse_varimax_loadings.tsv` |
| `OUT_PCHA_XP` | `local_data/res/l23_evo/14.mouse_pcha_xp.tsv` |
| `OUT_PCHA_AA` | `local_data/res/l23_evo/14.mouse_pcha_aa.tsv` |
| `OUT_HTML` | `local_data/fig/l23_evo/14.mouse_varimax_scatter.html` |

### Parameters
```python
MOUSE_SUBCLASS = 'L2/3'
CLUSTER_COL    = 'Type_leiden'
N_HVG          = 2000
N_PCS          = 10
NOC            = 3
NDIM           = 4   # NOC+1 PCs fitted, last dropped → 4D PCHA space
```

### Pipeline
1. Load h5ad → filter to `Subclass == 'L2/3'` (2213 cells)
2. Raw counts → `log2(CP10k + 1)` normalization
3. Select top `N_HVG=2000` genes by variance across mouse cells
4. `StandardScaler` → `PCA(n_components=N_PCS)` → save loadings
5. Apply `varimax()` (copy from `scripts/l23_evo/05.varimax_jorstad23.py:48–81`) to gene loadings → rotation R
6. Apply R to cell scores → varimax coords VX1–VX10 (reordered by descending variance)
7. Compute variance partitioning by `Type_leiden` (partial R² per VX component) — **print table** to identify subtype-informative components
8. Fit `SCA` + `proj_and_pcha(NDIM, NOC)` on all 10 VX cols
9. Save varimax coords (with `Type_leiden` metadata), loadings, `sca.xp`, `sca.aa.T`
10. Visualize: `scatter_categorical_html` on VX1/VX2/VX3 colored by `Type_leiden`, `aa_grid=[sca.aa]`

### Functions to reuse
- `varimax()` — copy from `scripts/l23_evo/05.varimax_jorstad23.py:48–81`
- `SCA`, `proj_and_pcha` — `src/scomics/main.py`
- `scatter_categorical_html` — `scripts/viz.py:207`

## Script 15: `scripts/l23_evo/15.map_mouse_harmony.py`

### Purpose
Build a shared gene space from human + mouse subtype-variation genes (via orthologs), align species with Harmony, find nearest human neighbors for each mouse cell in Harmony space, embed mouse cells in the original human PCHA space.

### User step between 14 and 15
After running script 14, inspect the variance partitioning printout and choose which mouse VX components have high `Type_leiden` R². Set `MOUSE_VX_COLS` in script 15 accordingly (e.g. `['VX1','VX2','VX3']`).

| `INPUT_MOUSE` | `links/l23_evo/yoo25_mouse_IT_P21.h5ad` |

### Pipeline

**Step 1 — Shared gene space**
```python
# Top 50 genes per component, deduplicated
human_vx_genes = [genes with top |loading| across HUMAN_VX_COLS]
mouse_vx_genes = [genes with top |loading| across MOUSE_VX_COLS]

# Ortholog dicts (1-to-1 only): h2m, m2h
# Gene pairs = union of:
#   (a) human VX gene → mouse ortholog present in mouse dataset
#   (b) mouse VX gene → human ortholog present in human dataset
# Deduplicate on (human_gene, mouse_gene) pair
```

**Step 2 — Joint expression matrix**
```python
# Human: h5ad.X already log-normalized → X_human (n_human × n_shared)
# Mouse: raw counts → log2(CP10k+1) → X_mouse (n_mouse × n_shared)
# X_joint = vstack([X_human, X_mouse])
# StandardScaler fit on X_joint → X_joint_scaled
```

**Step 3 — Joint PCA**
```python
pca = PCA(n_components=N_PCS_JOINT, random_state=0)
Z_pca = pca.fit_transform(X_joint_scaled)   # (n_total, 20)
```

**Step 4 — Harmony**
```python
meta = pd.DataFrame({'species': ['human']*n_human + ['mouse']*n_mouse})
ho   = harmonypy.run_harmony(Z_pca, meta, vars_use='species', random_state=0)
Z_corr = ho.Z_corr.T   # harmonypy returns (n_pcs, n_cells) → transpose → (n_cells, n_pcs)
Z_human = Z_corr[:n_human]
Z_mouse = Z_corr[n_human:]
```

**Step 5 — Nearest human neighbors in Harmony space (chunked cosine)**

Reuse l2norm + chunked cosine pattern from `scripts/l23_evo/12.map_mouse_jorstad23_space.py:127–146`.
Outputs: `topk_indices` (n_mouse × K), `topk_scores` (n_mouse × K).

**Step 6 — Hub diagnostic**
```python
unique, counts = np.unique(topk_indices, return_counts=True)
print(f"Unique human cells used: {len(unique)} / {n_human}")
# also report: how many cells cover 25/50/75% of neighbor slots
```
Target: unique cells >> 73 (script 12 baseline). If still collapsed, revisit gene space or Harmony theta.

**Step 7 — Embed mouse in human PCHA space**
```python
xp_human = pd.read_csv(IN_HUMAN_XP, sep='\t', index_col=0).values
weights  = topk_scores / topk_scores.sum(axis=1, keepdims=True)
mouse_xp = np.stack([weights[i] @ xp_human[topk_indices[i]] for i in range(n_mouse)])
```

**Step 8 — Visualize**
