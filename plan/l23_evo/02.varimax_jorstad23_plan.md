# Plan: Varimax Rotation Analysis of Jorstad23 Human L2/3 IT

## Context
Extension of the first-pass analysis (`01.first_pass_jorstad23_plan.md`). The variance partitioning (script 03) revealed that PC2 and PC3 have mixed cell-type and donor contributions, even though visually the two sources of variation appear approximately orthogonal. This is a rotation problem: PCA finds axes of maximum total variance, not axes aligned with biological factors. Varimax rotation of the gene loading matrix finds an orthogonal rotation within the PC subspace that maximizes sparsity of gene loadings — pushing each rotated component to load strongly on a distinct gene subset, which empirically produces cleaner factor separation.

**Key result:** VX2 (71% cell_type) and VX1 (70% library_size) emerge as near-pure axes after gene-loading varimax, versus the mixed PC2/PC3 in the original PCA.

## Script 5: `scripts/l23_evo/05.varimax_jorstad23.py`

**Purpose:** Apply Kaiser varimax rotation to the gene loading matrix, reorder components by descending variance, run variance partitioning on rotated components, and produce an HTML report with a top-gene table.

### File paths / config
```python
IN_PCA       = local_data/res/l23_evo/01.pca_coords.tsv
IN_LOADINGS  = local_data/res/l23_evo/01.pca_loadings.tsv
OUT_COORDS   = local_data/res/l23_evo/05.varimax_coords.tsv
OUT_LOADINGS = local_data/res/l23_evo/05.varimax_loadings.tsv
OUT_TSV      = local_data/res/l23_evo/05.variance_partition.tsv
OUT_HTML     = local_data/fig/l23_evo/05.variance_partition.html

N_PCS = 10
```

### Varimax algorithm
Kaiser varimax (gamma=1) via Jacobi pair-rotation sweeps on the gene loading matrix L (N_HVG × N_PCS). Returns orthogonal rotation matrix R (N_PCS × N_PCS).

```
L = loadings_df[pc_cols].values       # (N_HVG, N_PCS)
R = varimax(L)                         # find rotation from gene loadings
vx_scores   = scores   @ R            # apply same R to cell scores
vx_loadings = L        @ R            # rotated gene loadings
```

### Post-hoc reordering by descending variance
```python
vx_var_order = np.argsort(vx_scores.var(axis=0))[::-1]
vx_scores    = vx_scores[:, vx_var_order]
vx_loadings  = vx_loadings[:, vx_var_order]
```
VX1 now explains the most variance, VX2 the second, etc. (variance ordering is lost after rotation and restored here).

### Variance partitioning
Same partial-R² approach as script 03 (factors: cell_type, donor, source, library_size). Results printed per component and saved to `05.variance_partition.tsv`.

**Key finding:**
| Component | Dominant factor | Partial R² |
|-----------|----------------|------------|
| VX1 | library_size | 0.70 |
| VX2 | cell_type | 0.71 |
| VX5 | donor | 0.41 |

### HTML output
Stacked bar chart (plotly) with x-axis labels showing component + fraction of total variance (e.g. `VX2 (21%)`), followed by a gene-loading table:

```python
# x-axis labels include variance fraction
vx_var_frac = (vx_df[vx_cols].var() / vx_df[vx_cols].var().sum() * 100).round(1)
x_labels = [f'{col}<br>({vx_var_frac[col]}%)' for col in vx_cols]

# top-5 gene table appended below the plot
```
