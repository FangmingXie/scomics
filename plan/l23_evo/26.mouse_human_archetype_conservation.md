# Plan: Cross-species archetype conservation (script 26)

## Context

We have conservative one-vs-each Wilcoxon markers for 3 mouse archetypes (script 21,
~225 genes) and 4 human archetypes (script 25, ~364 genes). The question is: which
mouse archetypes correspond to which human archetypes (conserved vs. rewired), and
which specific genes drive that correspondence? We answer this via 1-to-1 ortholog
gene-overlap statistics, producing a 3×4 similarity matrix and per-pair gene tables.

## Analysis logic

### Step 1 — Load and map markers

```python
# build strict 1-to-1 dicts (drop_duplicates both columns, as in script 22)
ortho = pd.read_csv(IN_ORTHOLOGS, sep='\t').drop_duplicates('human_symbol').drop_duplicates('mouse_symbol')
mouse_to_human = dict(zip(ortho['mouse_symbol'], ortho['human_symbol']))
human_to_mouse = dict(zip(ortho['human_symbol'], ortho['mouse_symbol']))

# per-archetype gene sets
mouse_sets = {k: set of mouse marker genes for archetype_k}        # mouse gene symbols
human_sets = {j: set of human marker genes for archetype_j}        # human gene symbols
```

### Step 2 — 3×4 overlap statistics

Background `N` = total number of 1-to-1 ortholog pairs = len(ortho).

For each (mouse arch k, human arch j):
- Map mouse_sets[k] → human ortholog symbols: `M_orth` = {mouse_to_human[g] for g in mouse_sets[k] if g in mouse_to_human}
- Intersection: `shared` = M_orth ∩ human_sets[j]
- Jaccard: `|shared| / |M_orth ∪ human_sets[j]|`
- Hypergeometric (one-tailed, enrichment):
  - `K` = |M_orth|  (marked successes in population)
  - `n` = |human_sets[j]|  (draw size)
  - `k` = |shared|  (observed successes)
  - `p = scipy.stats.hypergeom.sf(k-1, N, K, n)`

Save a 3×4 Jaccard TSV and 3×4 p-value TSV (rows = mouse archetypes, cols = human archetypes).

### Step 3 — Per-pair gene conservation table

For every (mouse arch k, human arch j) pair, for every gene with a 1-to-1 ortholog
in either marker set, assign a status:

| status | condition |
|---|---|
| `conserved` | mouse gene in mouse_sets[k] AND its human ortholog in human_sets[j] |
| `mouse_only` | mouse gene in mouse_sets[k] AND its human ortholog NOT in human_sets[j] |
| `human_only` | human gene in human_sets[j] AND its mouse ortholog NOT in mouse_sets[k] |

Columns: `mouse_arch, human_arch, mouse_gene, human_gene, status, mouse_log2FC, human_log2FC`.

Save as `OUT_GENES`.

### Step 4 — Heatmap HTML

Plotly `go.Heatmap` (no viz.py helper exists for this):
- Rows: mouse archetypes A/B/C, Cols: human archetypes A/B/C/D
- Primary color: Jaccard score
- Annotation text per cell: `f"J={jaccard:.2f}\np={pval:.1e}\nn={n_shared}"`
- Second tab / toggle: −log10(p-value) as color

Single-page HTML via `plotly.io.write_html`.

### Step 5 — Conservation scatter HTML

One subplot per mouse archetype (3 subplots, arranged in a row):
- x-axis: mouse log2FC for all genes in mouse_sets[k] with a 1-to-1 ortholog
- y-axis: human log2FC of the same gene in the best-matched human archetype
  (best match = human archetype with highest Jaccard for this mouse archetype)
- Color by status: conserved (both marker sets) = colored, mouse_only = grey
- Hover text: gene name (mouse symbol)

Saved as a single HTML via plotly subplots.
