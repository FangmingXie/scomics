# Script 09: Archetype markers for Jorstad23 L2/3 IT (NOC=4)

## Context
Script 08 sweeps NOC values to select the best number of archetypes. Script 09 fixes NOC=4, finds the 300 cells closest to each archetype in VX subspace, and runs Wilcoxon enrichment to identify marker genes per archetype. Outputs: a TSV marker table and a gene expression HTML scatter.

## Parameters
```python
VX_COLS       = ['VX2', 'VX6', 'VX7', 'VX8', 'VX9', 'VX10']
NOC           = 4
NDIM          = 5        # same as script 08 (n_fit = NDIM+1 = 6 = len(VX_COLS))
N_TOP_CELLS   = 300
LOG2FC_THRESH = 0.5
FRAC_IN_THRESH= 0.25
N_TOP_GENES_VIZ = 5      # top genes per archetype for HTML
CLUSTER_COL   = 'WithinArea_cluster'
```

---

## Implementation Steps

### 1. Load varimax coords
```python
vx_df  = pd.read_csv(IN_VARIMAX, sep='\t', index_col=0)
xn     = vx_df[VX_COLS].values          # (n_cells, 6)
types  = vx_df[CLUSTER_COL].values
```

### 2. Fit PCHA at NOC=4 (same SCA setup as script 08)
```python
sca = SCA(xn, types)
sca.setup_feature_matrix(method='data')
sca.proj_and_pcha(NDIM, NOC)
# sca.xp: (n_cells, NDIM), sca.aa: (NDIM, NOC), sca.pca_: fitted PCA model
```

### 3. Back-project archetype coords to VX space, compute distances
```python
aa_vx = sca.pca_.inverse_transform(sca.aa.T)   # (NOC, len(VX_COLS))
# dists[i, k] = Euclidean distance of cell i from archetype k in VX space
dists = np.stack([np.linalg.norm(xn - aa_vx[k], axis=1) for k in range(NOC)], axis=1)
# top_cells[k] = indices of 300 cells closest to archetype k
top_cells = [np.argsort(dists[:, k])[:N_TOP_CELLS] for k in range(NOC)]
```

### 4. Load gene expression (HVGs only)
```python
adata      = ad.read_h5ad(INPUT_FILE)
hvg_genes  = pd.read_csv(IN_PCA_LOADINGS, sep='\t', index_col=0).index.values
gene_names = adata.var['feature_name'].values if 'feature_name' in adata.var.columns else adata.var_names.values
hvg_idx    = np.where(np.isin(gene_names, hvg_genes))[0]
X_norm     = adata.X[:, hvg_idx].toarray().astype(np.float32)   # (n_cells, n_hvg)
hvg_names  = gene_names[hvg_idx]
```

### 5. Wilcoxon enrichment per archetype (one-vs-rest)
Reuse the same pattern as `scripts/l23_evo/01.compute_jorstad23.py` lines 118–154:
- For each archetype k, `in_mask` = `top_cells[k]`, `out_mask` = complement
- Per gene: compute `log2FC`, `frac_in`, `frac_out`, Wilcoxon p-value
- BH FDR correction across genes
- Filter: `log2FC ≥ LOG2FC_THRESH` AND `frac_in ≥ FRAC_IN_THRESH`
- Label archetype as `f'archetype_{k+1}'`

Save all archetype marker rows to `OUT_MARKERS` (columns: `gene, archetype, log2FC, pval, fdr, frac_in, frac_out`).

### 6. Gene expression HTML
- For each archetype k, take top `N_TOP_GENES_VIZ` markers (sorted by FDR)
- Deduplicate gene list across archetypes
- Load expression for selected genes from h5ad (z-scored), same pattern as script 07
- Call `gene_expr_scatter_html()` from `scripts/viz.py` with VX2/VX6 as x/y axes, archetype vertices overlaid (`aa_vx[:, [0, 1]]` = VX2, VX6 columns)
- Save to `OUT_HTML`
