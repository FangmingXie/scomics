# Plan: Apply L2/3 IT Pipeline to Cheng22 Mouse Data

## Context

The human Jorstad23 pipeline (scripts 01–11 in `scripts/l23_evo/`) established a workflow: HVG selection → PCA → varimax rotation → variance partitioning → NOC sweep → PCHA archetype fitting → archetype marker discovery. Script 14 already applied a condensed version of this to mouse Yoo25 (P21) data.

The goal here is to apply the same full pipeline to mouse **Cheng22 (P28)** L2/3 IT data in three separate scripts (18, 19, 20), mirroring the human pipeline's structure but adapted for mouse data specifics.

---

## Data

- **Input**: `links/l23_evo/cheng22_mouse_IT_P28.h5ad` (11,061 cells × 16,572 genes, raw counts)
- **Filter to**: `Subclass == 'L2/3'` → ~4,044 cells
- **Cell type column**: `Type` (L2/3_A, L2/3_B, L2/3_C)
- **Batch/sample column**: `sample`
- **Library size column**: `n_counts` (confirm — also aliased as `total_counts`)
- **Normalization needed**: raw counts → log2(CP10k + 1) (same as script 14)

---

## Scripts to Create

### Script 18: `scripts/l23_evo/18.mouse_cheng22_varimax.py`

Mirrors scripts 01 + 05 combined. Compute PCA + varimax rotation + variance partitioning for Cheng22 L2/3.

**File path variables (top of script):**
```python
INPUT_MOUSE      = links/l23_evo/cheng22_mouse_IT_P28.h5ad
OUT_VX_COORDS    = local_data/res/l23_evo/18.mouse_varimax_coords.tsv
OUT_VX_LOADINGS  = local_data/res/l23_evo/18.mouse_varimax_loadings.tsv
OUT_PC_VAR_TSV   = local_data/res/l23_evo/18.mouse_pc_variance_partition.tsv
OUT_PC_VAR_HTML  = local_data/fig/l23_evo/18.mouse_pc_variance_partition.html
OUT_VX_VAR_TSV   = local_data/res/l23_evo/18.mouse_vx_variance_partition.tsv
OUT_VX_VAR_HTML  = local_data/fig/l23_evo/18.mouse_vx_variance_partition.html
```

**Parameters:**
```python
MOUSE_SUBCLASS = 'L2/3'
CLUSTER_COL    = 'Type'
SAMPLE_COL     = 'sample'
LIBSIZE_COL    = 'n_counts'   # verify column name in adata.obs
N_HVG          = 2000
N_PCS          = 10
```

**Steps:**
1. Load h5ad, filter `Subclass == 'L2/3'`
2. Normalize: raw counts → `log2(X / depth * 1e4 + 1)` (same as script 14 lines 100–103)
3. HVG selection by variance (top 2000)
4. StandardScaler + PCA(10)
5. **Variance partitioning on PCs** (before varimax): for each PC, compute partial R² for Type (one-hot), sample (one-hot), and nCounts (z-scored). Save TSV + Plotly stacked bar HTML. Reveals which raw PCs are biology vs. batch/depth dominated.
6. Varimax rotation (reuse `varimax()` function from script 14)
7. Reorder VX components by descending variance
8. **Variance partitioning on VX components** (after varimax): same partial R² decomposition (Type, sample, nCounts, residual) on the rotated scores. Save separate TSV + Plotly stacked bar HTML. Compare to step 5 to confirm varimax improved biological separation.
9. Save `18.mouse_varimax_coords.tsv` (cells × VX1–VX10 + Type + sample columns)
10. Save `18.mouse_varimax_loadings.tsv` (genes × VX1–VX10)

**Key reuse:**
- `varimax()` function: copy from script 14 (lines 53–80) or script 05
- `r2()` helper: copy from script 14 (lines 83–87)
- Partial R² loop pattern: copy from script 05 (compute R²_full then R²_reduced per covariate)
- Stacked bar + top-genes HTML: script 05 lines 161–221

### Script 20: `scripts/l23_evo/20.mouse_cheng22_archetype_markers.py`

Mirrors script 09.2 + HTML scatter from script 14. Fit PCHA at selected NOC, identify archetype marker genes.

**File path variables:**
```python
IN_VX_COORDS   = local_data/res/l23_evo/18.mouse_varimax_coords.tsv
INPUT_MOUSE    = links/l23_evo/cheng22_mouse_IT_P28.h5ad
IN_VX_LOADINGS = local_data/res/l23_evo/18.mouse_varimax_loadings.tsv
OUT_MARKERS    = local_data/res/l23_evo/20.mouse_archetype_markers.tsv
OUT_PCHA_XP    = local_data/res/l23_evo/20.mouse_pcha_xp.tsv
OUT_PCHA_AA    = local_data/res/l23_evo/20.mouse_pcha_aa.tsv
OUT_HTML       = local_data/fig/l23_evo/20.mouse_archetype_scatter.html
```

**Parameters:**
```python
MOUSE_SUBCLASS = 'L2/3'
CLUSTER_COL    = 'Type'
# Same VX_COLS as script 19 — update after inspecting script 18 output:
VX_COLS        = ['VX2', 'VX3', 'VX4', 'VX5', 'VX6', 'VX7']
NOC            = 3       # update after inspecting script 19 metrics plot
NDIM           = len(VX_COLS) - 1   # 5
N_TOP_CELLS    = 300
FRAC_IN_THRESH = 0.25
FDR_THRESH     = 0.001
```

**Steps:**
1. Load varimax coords + h5ad (filter to L2/3, normalize same as script 18)
2. Load HVG gene list from `IN_VX_LOADINGS` index; slice normalized expression matrix
3. Fit PCHA: `sca.proj_and_pcha(NDIM, NOC)` → `sca.xp`, `sca.aa`
4. Back-project archetype coords to VX space: `aa_vx = sca.aa.T @ sca.pca_.components_[:NDIM] + sca.pca_.mean_`
5. Top 300 nearest cells per archetype (Euclidean in VX space)
6. Wilcoxon rank-sum per gene, FDR-BH correction; filter `frac_in >= 0.25`, `fdr < 0.001`
7. Save `20.mouse_archetype_markers.tsv`, `20.mouse_pcha_xp.tsv`, `20.mouse_pcha_aa.tsv`
8. Interactive HTML scatter (VX PCHA space, colored by Type + archetype assignment) — reuse `scatter_categorical_html` from `scripts/viz.py`

**Key reuse:**
- Normalization: script 18 / script 14 lines 100–103
- PCHA fit + save: script 09.2 lines 53–62
- Back-projection: script 09.2 line 67
- Wilcoxon loop: script 09.2 lines 87–129 (use `adata.var_names.values` directly for mouse)
- HTML scatter: script 14 lines 165–176
