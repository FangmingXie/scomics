# Plan: Human Archetype Scores Script (25) for Jorstad23 L2/3 IT

## Context

Script 21 computes conservative one-vs-each Wilcoxon markers and per-cell archetype scores for the 3 mouse archetypes (Cheng22). Script 09 computes one-vs-rest markers for the 4 human archetypes (Jorstad23) but uses the old approach and produces no scores. The user wants a new script `25` that applies the same conservative test and score computation to the 4 human archetypes — directly mirroring script 21 but adapted for the human data.

```python
VX_COLS         = ['VX2', 'VX6', 'VX7', 'VX8', 'VX9', 'VX10']  # human VX cols (not mouse's VX1)

```

### Key adaptations from script 21

1. **HVG list**: load from `01.pca_loadings.tsv` (not `18.mouse_varimax_loadings.tsv`)
2. **Gene name access**: use `adata.var['feature_name']` if available, else `adata.var_names` (same pattern as scripts 09, 22)
3. **Expression matrix**: `.X` is already log-normalized — skip the raw-count normalization step (unlike mouse script 21 lines 98–101)
4. **Cell metadata**: only CLUSTER_COL (`WithinArea_cluster`); no SAMPLE_COL used

### Logic (unchanged from script 21)

- PCHA fit → back-project archetype coords to VX space → select N_TOP_CELLS per archetype
- Conservative one-vs-each Wilcoxon: for each archetype k, compare against each other archetype j separately; keep max p-value and min log2FC; apply FDR; filter by frac_in, FDR, log2FC
- Archetype score: normalize each marker gene's expression to [0,1] (2nd–98th pctile clip), then average across all marker genes
- Visualize: PCHA scatter (categorical) + score scatter (gene_expr_scatter_html with dropdown)

### Reused utilities
- `scatter_categorical_html`, `gene_expr_scatter_html` from `scripts/viz.py`
- `SCA.proj_and_pcha()` from `scomics/main.py`
