# Script 16: Map mouse L2/3 IT into human VX archetype space via Sinkhorn-Knopp

## Context

Script 12 collapsed the mouse manifold onto ~73 hub human cells (50% of neighbor slots). The root
cause is that top-k assignment in a species-mean-dominated gene space sends all mouse cells to the
same small pocket of human cells.

Script 16 fixes the assignment step — not the gene space — by replacing top-k with
Sinkhorn-Knopp (SK) balanced assignment. SK iteratively normalizes rows and columns of the
similarity matrix until each human cell attracts equal total mouse mass, eliminating hubs by
construction. To make the full similarity matrix tractable, human cells are first downsampled to
20% (~9,425 cells), reducing the matrix from 417 MB to ~83 MB.

**Assumption**: hub collapse in script 12 is a gene-space artifact, not genuine biology (i.e.,
mouse cells are approximately uniformly distributed across human subtypes). If that assumption is
wrong the SK-forced balance will be visible as implausibly uniform mouse coverage.

### Step 7: Sinkhorn-Knopp iteration

```python
def sinkhorn(S, tau, max_iter, tol):
    """Entropy-regularized balanced assignment via Sinkhorn-Knopp.

    Finds doubly stochastic P (up to marginal scaling) where:
      row marginals = 1/n_mouse  (each mouse cell distributes unit mass)
      col marginals = 1/n_human  (each human cell receives equal mass)

    Returns P (n_mouse × n_human_sub), row-normalized for embedding.
    """
    n_mouse, n_human = S.shape
    # exponentiate with temperature — shift by row max for numerical stability
    log_P = S / tau
    log_P -= log_P.max(axis=1, keepdims=True)
    P = np.exp(log_P).astype(np.float64)

    r_target = np.full(n_mouse,  1.0 / n_mouse)   # uniform row marginal
    c_target = np.full(n_human,  1.0 / n_human)   # uniform col marginal

    for i in range(max_iter):
        # row normalize
        P /= P.sum(axis=1, keepdims=True) * n_mouse * n_human  # scale to marginals
        # re-derive: simpler to just alternate divide
        row_sums = P.sum(axis=1)
        P /= row_sums[:, None]
        P *= r_target[:, None] * n_mouse   # rescale so rows sum to r_target

        # col normalize
        col_sums = P.sum(axis=0)
        P /= col_sums[None, :]
        P *= c_target[None, :] * n_human

        # convergence check
        row_err = np.abs(P.sum(axis=1) - r_target).max()
        col_err = np.abs(P.sum(axis=0) - c_target).max()
        if max(row_err, col_err) < tol:
            print(f'  SK converged at iteration {i+1}  '
                  f'(row_err={row_err:.2e}, col_err={col_err:.2e})')
            break
    else:
        print(f'  SK did not converge in {max_iter} iters  '
              f'(row_err={row_err:.2e}, col_err={col_err:.2e})')
    return P   # (n_mouse, n_human_sub), rows sum to r_target

P = sinkhorn(S, SK_TAU, SK_MAX_ITER, SK_TOL)
del S   # free memory
```

```python
# Effective number of human cells used per mouse cell (inverse participation ratio)
# High = spread assignment; Low = concentrated (hub-like)
w_norm = P / P.sum(axis=1, keepdims=True)           # row-normalize to sum=1
eff_n  = 1.0 / (w_norm ** 2).sum(axis=1)            # (n_mouse,) — effective N per mouse cell
print(f'Effective human cells per mouse cell:')
for pct in [5, 25, 50, 75, 95]:
    print(f'  p{pct}: {np.percentile(eff_n, pct):.1f}')

# Column marginal spread: how evenly are human cells used?
col_marginals = P.sum(axis=0)                        # (n_human_sub,)

      f'mean={col_marginals.mean():.4f}  '
      f'std={col_marginals.std():.4f}  '
      f'cv={col_marginals.std()/col_marginals.mean():.3f}')
# CV → 0 means perfectly balanced; high CV means hub-like
```

## Key design decisions

**Why downsample before SK, not after?**
SK must be run on the matrix used for embedding. Downsampling human first ensures
the balanced marginal constraint applies to the cells that actually contribute to
the mouse embedding — not a post-hoc subsample.

**Temperature τ=0.05 rationale**
Cosine similarities in script 12 ranged ~0.58–0.78 (std ≈ 0.03–0.05 within top-k).
τ=0.05 ≈ 1× std of the similarity distribution → reasonable entropy, not too peaked.
If the hub diagnostic shows CV still high → increase τ. If mouse coords look uniform
and unstructured → decrease τ.

**Row vs column normalization order**
Row-first means each mouse cell first distributes its mass, then columns are
rebalanced. Either order converges to the same fixed point; row-first is
conventional.

**Numerical stability**
Subtract row maximum before exponentiation (`log_P -= log_P.max(axis=1, keepdims=True)`)
to prevent overflow when τ is small.
