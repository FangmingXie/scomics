# Plan: First-Pass Analysis of jainlab26_cux2cre with Harmony Label Transfer

## Context
First-pass analysis of a new Cux2-Cre single-cell RNA-seq dataset (`jainlab26_cux2cre`, 21,321 cells × 50,763 genes). The goal is to annotate cells by transferring `Subclass` labels from the P21 reference dataset (`yoo25_P21.h5ad`, 11,994 cells × 16,572 genes, 20 subclasses) using Harmony for batch-corrected joint embedding, then save a labeled h5ad and visualize UMAPs.

---

## Script

**New file**: `scripts/cux2cre/00.first_pass_jainlab26_cux2cre.py`

Output dataset subfolder: `cux2cre` (i.e., `local_data/res/cux2cre/`, `local_data/fig/cux2cre/`)

---

## Implementation Steps

### File paths (defined at top, capitalized)
```python
INPUT_TARGET_H5   = 'links/cux2cre/filtered_feature_bc_matrix_jainlab26_cux2cre.h5'
INPUT_REF_H5AD    = 'links/cux2cre/yoo25_P21.h5ad'
OUT_H5AD          = 'local_data/res/cux2cre/00.jainlab26_cux2cre_labeled.h5ad'
OUT_FIG_SOURCE    = 'local_data/fig/cux2cre/00.umap_datasource.html'
OUT_FIG_SUBCLASS  = 'local_data/fig/cux2cre/00.umap_subclass.html'
```

### Parameters (defined at top)
```python
N_HVG       = 3000
N_PCS       = 30
N_NEIGHBORS = 15  # for kNN label transfer
```

### Step 1: Load data
- Target: `sc.read_10x_h5(INPUT_TARGET_H5)` → AnnData (21,321 × 50,763)
- Reference: `sc.read_h5ad(INPUT_REF_H5AD)` → AnnData (11,994 × 16,572)
- Add `obs['source']` column: `'jainlab26'` for target, `'yoo25'` for reference

### Step 2: Basic QC on target
- Compute `n_genes_by_counts` and `total_counts` per cell (`sc.pp.calculate_qc_metrics`)
- Filter: cells with `n_genes_by_counts < 200` or `total_counts < 500`
- Make var_names unique: `adata.var_names_make_unique()`

### Step 3: Find shared genes and select HVGs
- Shared genes: `np.intersect1d(target.var_names, ref.var_names)`
- Subset both to shared genes
- Select top `N_HVG` HVGs by per-gene variance computed on CP10k log1p-normalized reference
- Subset both to those HVGs

### Step 4: Normalize both datasets
- Raw counts → `np.log1p(X / depths * 1e4)` (CP10k log1p) for each dataset independently

### Step 5: Joint PCA
- Stack: `X_joint = np.vstack([X_ref_hvg_norm, X_target_hvg_norm])`
- `StandardScaler().fit_transform(X_joint)`
- `PCA(n_components=N_PCS, random_state=0).fit_transform(X_joint_scaled)`
- Split PCA embeddings back into ref/target portions

### Step 6: Harmony batch correction
```python
import harmonypy
meta_df = pd.DataFrame({'source': ['yoo25'] * n_ref + ['jainlab26'] * n_target})
ho = harmonypy.run_harmony(Z_pca, meta_df, vars_use='source', random_state=42)
Z_harmony = ho.Z_corr.T  # shape: (n_cells_total, N_PCS)
```
Split into `Z_harmony_ref` and `Z_harmony_target`.

### Step 7: kNN label transfer in Harmony space
```python
from sklearn.neighbors import KNeighborsClassifier
knn = KNeighborsClassifier(n_neighbors=N_NEIGHBORS, metric='euclidean')
knn.fit(Z_harmony_ref, ref.obs['Subclass'].values)
pred_subclass = knn.predict(Z_harmony_target)
pred_proba    = knn.predict_proba(Z_harmony_target)
```
Add to target obs: `Subclass_transferred` and `Subclass_max_prob`.

### Step 8: UMAP on all cells (Harmony space)
```python
import umap
reducer = umap.UMAP(n_neighbors=15, n_components=2, random_state=42)
Z_umap = reducer.fit_transform(Z_harmony)  # all cells together
```
Store in target `obsm['X_umap']` and `obsm['X_harmony']`.

### Step 9: Save labeled target h5ad
- `target.write_h5ad(OUT_H5AD)`

### Step 10: Visualize UMAPs
Use `scatter_categorical_html` from `scripts/viz.py`:

- **Plot 1** (`OUT_FIG_SOURCE`): All cells colored by `source` (`'yoo25'` vs `'jainlab26'`)
- **Plot 2** (`OUT_FIG_SUBCLASS`): All cells colored by `Subclass` (ref ground truth + target transferred)
