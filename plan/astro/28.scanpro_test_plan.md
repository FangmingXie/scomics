# Plan: Script 28 — Scanpro Test for Archetype Abundance (NR vs DR)

## Context

Script 27 visualizes archetype (cell type) abundance across cheng22 age/condition groups:
- **NR (Normal Reared)**: `P28`, `P38`
- **DR (Dark Reared)**: `P28_dr`, `P38_dr`
- **DL (Dark + Light)**: `P28_dl`

The goal is to test whether archetype abundance shifts between NR and DR are statistically significant using **scanpro** (Python equivalent of propeller), which models cell type proportions with empirical Bayes moderation accounting for biological replicates.

## New File

**`scripts/astro/28.scanpro_test.py`**

## Data Source

- Input: `local_data/res/astro/26.combined_labels.parquet`
- Columns used: `dataset`, `age`, `donor_name`, `archetype`
- Filter to `dataset == 'cheng22'` only

## Comparisons

One combined test merging both ages:
- **NR**: `age in ['P28', 'P38']`
- **DR**: `age in ['P28_dr', 'P38_dr']`

(P28_dl excluded — it is a separate DL condition, not NR or DR.)

## Implementation

### File paths (capitalized, at top of script)

```python
PARQUET_IN  = os.path.join(PROJECT_ROOT, 'local_data', 'res', 'astro', '26.combined_labels.parquet')
OUT_NR_DR   = os.path.join(PROJECT_ROOT, 'local_data', 'res', 'astro', '28.scanpro_NR_vs_DR.csv')
```

### Key logic

```python
from scanpro import scanpro

df = pd.read_parquet(PARQUET_IN)
df = df[df['dataset'] == 'cheng22'].reset_index(drop=True)

NR_AGES = ['P28', 'P38']
DR_AGES = ['P28_dr', 'P38_dr']

sub = df[df['age'].isin(NR_AGES + DR_AGES)].copy()
sub['condition'] = sub['age'].isin(NR_AGES).map({True: 'NR', False: 'DR'})

res = scanpro(sub, clusters_col='archetype', conds_col='condition', samples_col='donor_name')
res.results.to_csv(OUT_NR_DR)
print(f'Saved {OUT_NR_DR}')
```

### Output CSV

`28.scanpro_NR_vs_DR.csv` — scanpro result columns per archetype: estimated proportions per condition, t-statistic, p-value, FDR-adjusted p-value.
