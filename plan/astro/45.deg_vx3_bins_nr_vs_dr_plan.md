# Plan: Script 45 — VX3-Binned NR vs DR DEG Analysis

## Context

Scripts 44 and 29 together answer two complementary questions:
- Script 44: Where do DR cells sit in the NR VX (varimax) embedding space?
- Script 29: Which genes differ between NR and DR cells, broken down by archetype?

This new script (45) asks a third question: **do visual-dependent gene expression differences (NR vs DR) vary along the VX3 axis?** VX3 is the third varimax component from the NR Arch1+Arch2 space. By binning all cells into 4 equal-size quantile bins along VX3 and running an NR-vs-DR LMM within each bin, we can detect whether the DR transcriptional signature is spatially graded across the VX embedding.

## Implementation Plan

### 1. File paths (top-of-script constants, as per CLAUDE.md)

```python
INPUT_H5AD         = links/astro/cheng22_astro.h5ad
IN_COMBINED_LABELS = local_data/res/astro/26.combined_labels.parquet
IN_NR_H5AD         = local_data/res/astro/41.cheng22_nr_harmony_arch12.h5ad
OUT_DIR            = local_data/res/astro/
```

### 2. Data loading — mirror script 44 exactly

Copy the loading block from script 44:
- Load `adata_nr` → extract `vx_load`, `hvg_names`, `vx_scores_nr`, `pca_mean`, metadata
- Load `df_combined` parquet → `labels_c22`
- Load `adata` (full h5ad) → filter MT genes, filter by age
- Compute `x`, `depths`
- Get `hvg_col_idx`
- Normalize all cells: `xn_all = norm(x[:, hvg_col_idx], depths)`
- Identify `nr_idx_in_adata` (from barcode map), `dr_idx_in_adata` (from age mask)
- Regress library size from DR cells → `xn_dr`
- Project DR: `vx_scores_dr = (xn_dr - pca_mean) @ vx_load`

### 3. Build combined VX3 array

```python
vx3_combined = np.concatenate([vx_scores_nr[:, 2], vx_scores_dr[:, 2]])
# label each position as NR (0) or DR (1)
condition_code = np.array([0]*n_nr + [1]*n_dr)
sample_combined = np.concatenate([samples_nr, samples_dr])
combined_idx    = np.concatenate([nr_idx_in_adata, dr_idx_in_adata])
```

### 4. Bin assignment (equal-size quantiles **within each sample**)

Bin each sample independently so every donor contributes ~equal cell fractions to each bin, avoiding donor-composition bias.

```python
N_BINS = 4
bin_labels = np.full(len(vx3_combined), -1, dtype=int)
for sample in np.unique(sample_combined):
    mask = sample_combined == sample
    bin_labels[mask] = pd.qcut(vx3_combined[mask], q=N_BINS, labels=False, duplicates='drop')
```

Report per-bin cell counts (NR vs DR breakdown) to stdout.

### 5. DEG loop per bin — reuse script 29 structure

For each bin `b in range(N_BINS)`:
1. `mask = (bin_labels == b)`
2. Extract:
   - `logcpm_bin`: CP10k+log1p from raw counts `x[combined_idx[mask]]`
   - `obs_bin`: DataFrame with `condition_code`, `sample`
3. Gene filter: expressed in ≥ `MIN_EXPR_FRAC=0.1` of cells in this bin
4. LMM per gene: `smf.mixedlm('expr ~ condition_code', groups=sample)` with fallback methods [lbfgs, powell, nm]
5. FDR (BH), threshold 0.05
6. Save `45.deg_vx3_bin{b+1}_NR_vs_DR_all.tsv` and `..._sig.tsv`

Config constants (same as script 29):
```python
N_BINS        = 4
FDR_THRESH    = 0.05
MIN_EXPR_FRAC = 0.1
```
