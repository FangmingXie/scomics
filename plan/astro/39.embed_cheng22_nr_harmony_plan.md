# Plan: Script 39 — cheng22 NR embedding with Harmony donor correction

## Context

Script 37 (`scripts/astro/37.embed_cheng22_nr.py`) embeds cheng22 P28+P38 NR astrocytes via PCA → varimax → UMAP → Leiden. Variance partitioning (script 38) revealed that donor (`Sample`) explains a substantial fraction of variance in several PCA and VX components (e.g. PC3 R²=0.49 donor, VX4 R²=0.47 donor). Script 39 adds a Harmony batch correction step between PCA and varimax to suppress donor effects before downstream embedding.

**Is Harmony a good option?** Yes — it is the right choice here:
- Already installed (`harmonypy 2.0.0`) and used throughout this codebase (scripts 22, 24, 26, cux2cre/00, l23_evo/15, retina/01)
- Operates directly on PCA coordinates — slots naturally into the existing PCA → varimax → UMAP pipeline
- Fast and lightweight for ~3650 cells
- Single batch variable (`Sample`) is clean; no over-correction risk

## Implementation

Script 39 is script 37 with one Harmony step inserted after PCA and before varimax. Everything else (file paths, HVG selection, normalization, varimax, UMAP, Leiden, visualization) is identical.

### Change from script 37

After `pca_scores = pca.transform(xn_nr)` and before varimax:

```python
import harmonypy as hm

meta_df = pd.DataFrame({'Sample': donors[nr_indices]})
ho = hm.run_harmony(pca_scores, meta_df, 'Sample', random_state=0)
pca_scores_h = ho.Z_corr   # (n_nr, N_PCS), donor-corrected

# varimax, UMAP, Leiden all use pca_scores_h instead of pca_scores
```

Downstream steps use `pca_scores_h`:
- `vx_scores = pca_scores_h @ R` (varimax on corrected scores)
- `reducer.fit_transform(pca_scores_h)` (UMAP)
- `nn.fit(pca_scores_h)` (Leiden kNN)

### h5ad obsm slots saved

| slot | content |
|------|---------|
| `X_pca` | raw PCA scores (before harmony) |
| `X_harmony` | harmony-corrected PCA scores |
| `X_vx` | varimax of harmony-corrected scores |
| `X_umap` | UMAP of harmony-corrected scores |

varm slots (`PCA_loadings`, `VX_loadings`) and obs columns (`archetype`, `leiden`, `depth`) unchanged.

### Key constants (same as script 37)

`N_HVG=2000`, `N_PCS=10`, `MIN_CELLS=50`, `N_NEIGHBORS=30`, `LEIDEN_RESOLUTION=0.5`
