# Plan: Script 37 — PCA/Varimax/UMAP/Leiden for cheng22 NR ages

## Context

Script 33.3 fits PCA + varimax on cheng22 P28NR cells only and saves loadings/scores for downstream algebraic projection. Script 37 extends this to include **both P28NR and P38NR cells**, adds UMAP and Leiden clustering, packages everything into an h5ad, and generates a single two-panel HTML visualization.

## File

**New file:** `scripts/astro/37.embed_cheng22_nr.py`

| | Path |

## Key Constants

```python
LABELED_AGES      = ['P28', 'P28_dl', 'P28_dr', 'P38', 'P38_dr']  # for parquet alignment
NR_AGES           = ['P28', 'P38']    # selection: both NR time points
N_HVG             = 2000
N_PCS             = 10
MIN_CELLS         = 50
N_NEIGHBORS       = 30
LEIDEN_RESOLUTION = 0.5
GENES             = ['Gfap', 'Apoe', 'Mfge8', 'Id3', 'Lama3', 'Trpm3', 'Il33']
```

## Implementation Steps

### 1. Load & pre-filter (same as 33.3)
- Read h5ad, remove MT genes, filter to ages with >MIN_CELLS cells.

### 2. Load arch labels from parquet (same pattern as 33.3)
- Filter to cheng22 dataset; assert row count == `labeled_mask.sum()`.
- `labeled_mask = np.isin(ages, LABELED_AGES)`.

### 3. Select NR cells (P28 + P38) — all archetypes including Arch4
- `nr_mask_in_labeled = np.isin(ages[labeled_mask], NR_AGES)`
- `nr_indices` = the corresponding adata row indices (no Arch4 exclusion).
- Track `arch_labels`, `ages[nr_indices]`, `donors[nr_indices]`.

### 4. HVG selection on ALL NR cells
- `hvg_mask = select_hvg(x[nr_indices], depths[nr_indices], N_HVG)`

### 5. Normalize all NR cells
- `xn = norm(x[:, hvg_mask], depths)`; `xn_nr = xn[nr_indices]`
- `norm()` = CP10k → log2(1+x) → z-score per gene

### 6. Fit PCA on ALL NR cells
- `pca.fit(xn_nr)` → `pca_scores = pca.transform(xn_nr)`  (n_nr × N_PCS)

### 7. Varimax rotation
- Fit on full NR loadings: `R = varimax(pca.components_.T)`.
- Reorder components by descending variance of `pca_scores @ R`.
- `vx_scores = pca_scores @ R_reordered`
- `vx_loadings = pca.components_.T @ R_reordered`

### 8. UMAP on PCA scores (N_NEIGHBORS=30)
- `umap.UMAP(n_neighbors=N_NEIGHBORS, n_components=2, random_state=0).fit_transform(pca_scores)`

### 9. Leiden clustering (leidenalg + igraph)
- Note: scanpy is broken in the archetype env due to a matplotlib metaclass conflict in its plotting module.
- Use `NearestNeighbors(n_neighbors=N_NEIGHBORS + 1)` and drop the 0th neighbor column — sklearn returns each point as its own nearest neighbor (distance=0), which creates spurious 1/ε self-loop weights that break Leiden (produces one cluster per cell).
- Deduplicate edges as `(min(i,j), max(i,j))` pairs into a set before passing to igraph (avoids multi-edges in the undirected graph).
- Run `leidenalg.find_partition(g, RBConfigurationVertexPartition, resolution_parameter=0.5, seed=0)` with binary edges (no weight argument).
- Label clusters as `l{i}` where i is integer membership index.

### 10. Assemble and save h5ad
- `adata_out = adata[nr_indices, hvg_mask]` — subset cells and HVG genes.
- `adata_out.X` = normalized HVG expression (float32).
- `adata_out.obs`: all original obs columns + `archetype` + `leiden`.
- `adata_out.obsm['X_pca']`  = PC scores  (n_nr × N_PCS)
- `adata_out.obsm['X_vx']`   = VX scores  (n_nr × N_PCS)
- `adata_out.obsm['X_umap']` = UMAP coords (n_nr × 2)
- `adata_out.varm['PCA_loadings']` = (n_hvg × N_PCS)
- `adata_out.varm['VX_loadings']`  = (n_hvg × N_PCS)

### 11. Visualization — single HTML, two panels
- Panel 1 (categorical): `scatter_2d_categorical_html(..., return_html=True)` — toggles Type / archetype / leiden / Sample.
- Panel 2 (gene expr): `gene_expr_scatter_html(..., return_html=True)` — dropdown over 7 genes. Expression = log2(1+CP10k), z-scored per gene.
- Combined: `<html><body>{html1}{html2}</body></html>` written to `37.umap.html`.
- `return_html=True` was already present in `scatter_2d_categorical_html`; added to `gene_expr_scatter_html` in `scripts/viz.py`.
