# Plan: DEG Analysis per Archetype — NR vs DR (Script 29)

## Context
Following cross-dataset integration in script 26 (cheng22 + P28_dl, gao25 reference, Harmony + 10 PCs), each cheng22 cell has an archetype label (Arch1–4). This script tests differential expression between normal-rearing (NR: P28, P38) and dark-rearing (DR: P28_dr, P38_dr) conditions **within each archetype**, using a linear mixed model (LMM) with sample as random effect. P28_dl cells are excluded.

---

## Input / Output Files

```python
PARQUET_COMBINED  = local_data/res/astro/26.combined_labels.parquet
INPUT_CHENG22     = links/astro/cheng22_astro.h5ad

# Per archetype (4 archetypes × 2 files = 8 files)
OUT_ALL  = local_data/res/astro/29.deg_{archetype}_NR_vs_DR_all.tsv
OUT_SIG  = local_data/res/astro/29.deg_{archetype}_NR_vs_DR_sig.tsv
```

---

## Parameters

```python
CHENG22_AGES  = ['P28', 'P28_dl', 'P28_dr', 'P38', 'P38_dr']  # same as script 26
NR_AGES       = ['P28', 'P38']
DR_AGES       = ['P28_dr', 'P38_dr']
# P28_dl excluded
FDR_THRESH    = 0.05
MIN_EXPR_FRAC = 0.1
```

---

## Steps

### 1. Load & Align
- Load `26.combined_labels.parquet`; extract cheng22 rows (`dataset == 'cheng22'`)
- Load cheng22 h5ad, subset to `CHENG22_AGES` (identical to script 26) → `adata_cheng22`
- Assign `adata_cheng22.obs_names` to parquet cheng22 rows by positional alignment (both ordered identically)
- Subset to NR/DR ages (drop P28_dl)

### 2. Normalize
- Dense float32 raw counts, CP10k + log1p

### 3. Per-Archetype DEG Loop
For each archetype in `['Arch1', 'Arch2', 'Arch3', 'Arch4']`:
- Subset cells
- Gene filter: `>= MIN_EXPR_FRAC` expressed
- LMM per gene with fallback optimizers `['lbfgs', 'powell', 'nm']`:
  ```python
  smf.mixedlm('expr ~ condition_code', data=df, groups=df['sample']).fit(reml=True, ...)
  ```
- `log2FC = coef / log(2)`, FDR via BH correction
- Save all + sig TSV

---

## Output Schema
| gene | log2FC | pval | fdr |

Positive log2FC = higher in DR vs NR.
