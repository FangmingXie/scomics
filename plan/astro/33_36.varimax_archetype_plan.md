# Plan: Apply L2/3 IT Evo Workflow to Astrocyte Data (gao25)

## Context

Apply the three-step L2/3 IT evolution workflow to `gao25_scrna_astro.h5ad`:
1. **Varimax rotation** on P56 reference cells → separate biological from technical axes
2. **PCHA archetype decomposition** on varimax subspace → re-examine subtype structure
3. **Cross-age projection** → embed all postnatal ages into P56 archetype space

**Reference population**: P56 gao25 astrocytes (~5,309 cells), analogous to the ~47k human L2/3 IT neurons.

**Pre-annotated groups**: Use existing **Arch1-4** labels from `17.labels_all_ages.parquet` (NOC=4, kNN-transferred) as the cell-type factor in variance partitioning — analogous to the 6 pre-annotated L2/3 IT clusters in Jorstad23. The 5 original `cluster_label` values are dominated by one cluster (NN_3: 29k/32k cells) and are less useful for partitioning.

**Mapping direction**: Same species, no orthologs needed. Project all postnatal ages (P0–P56) through the P56-fitted PCA+varimax+inner-PCA pipeline algebraically.

**New scripts**: Continue numbering from 33 in `scripts/astro/`.

## Script 33: `33.varimax_p56_gao25.py`

Analogous to `scripts/l23_evo/05.varimax_jorstad23.py`.

**Inputs** (capitalized at top of script):
```
INPUT_H5AD          = 'links/astro/gao25_scrna_astro.h5ad'
IN_ARCH_LABELS      = 'local_data/res/astro/17.labels_all_ages.parquet'
```

**Outputs**:
```
OUT_VX_COORDS       = 'local_data/res/astro/33.varimax_coords.tsv'      # P56 × VX1..VX10 + metadata
OUT_VX_LOADINGS     = 'local_data/res/astro/33.varimax_loadings.tsv'    # HVGs × VX1..VX10
OUT_VAR_PARTITION   = 'local_data/res/astro/33.variance_partition.tsv'
OUT_PCA_COMPONENTS  = 'local_data/res/astro/33.pca_components.tsv'      # N_PCS × n_hvg
OUT_PCA_MEAN        = 'local_data/res/astro/33.pca_mean.tsv'            # 1 × n_hvg
OUT_VARIMAX_R       = 'local_data/res/astro/33.varimax_R.tsv'           # N_PCS × N_PCS (reordered)
OUT_VAR_PART_HTML   = 'local_data/fig/astro/33.variance_partition.html'
```

**Key parameters**: `N_HVG=2000`, `N_PCS=10`, `P56_AGE='P56'`

**Steps**:
1. Load h5ad; filter to postnatal ages with >50 cells.
2. Compute `depths = x.sum(axis=1)` on raw counts (no `nCount_RNA` column).
3. Select HVGs using `select_hvg(x[p56_mask], depths[p56_mask], N_HVG)` from `common.py`.
4. Normalize ALL postnatal cells jointly: `xn = norm(x[:, hvg_mask], depths)` from `scomics.utils`.
5. Join Arch1-4 labels to P56 cells from `17.labels_all_ages.parquet` by barcode index.
6. Fit `sklearn.decomposition.PCA(N_PCS)` on P56 cells only; extract `L = pca.components_.T` (n_hvg × N_PCS).
7. Copy `varimax(L)` function from `05.varimax_jorstad23.py`; apply rotation; reorder by descending variance.
8. Copy `r2(X, y)` for variance partitioning; factors = Arch1-4 (one-hot), donor_name (one-hot), library_size (zscore of depths). Three factors (no Source/development_stage).
9. Save all outputs including the three PCA parameter files (`pca_components`, `pca_mean`, `varimax_R`) needed for script 36.

**Note**: `var_names` are gene symbols directly; no `feature_name` column. Genes accessed as `adata.var_names.values`.

## Script 36: `36.map_ages_p56_space.py`

Analogous to `12.map_mouse_jorstad23_space.py` but same species → direct algebraic projection (no orthologs, no cosine similarity).

**Inputs**:
```
INPUT_H5AD          = 'links/astro/gao25_scrna_astro.h5ad'
IN_VX_LOADINGS      = 'local_data/res/astro/33.varimax_loadings.tsv'      # HVG gene list
IN_PCA_COMPS        = 'local_data/res/astro/33.pca_components.tsv'
IN_PCA_MEAN         = 'local_data/res/astro/33.pca_mean.tsv'
IN_VARIMAX_R        = 'local_data/res/astro/33.varimax_R.tsv'
IN_INNER_COMPS      = 'local_data/res/astro/35.inner_pca_components.tsv'
IN_INNER_MEAN       = 'local_data/res/astro/35.inner_pca_mean.tsv'
IN_XP_P56           = 'local_data/res/astro/35.pcha_xp.tsv'
IN_AA               = 'local_data/res/astro/35.pcha_aa.tsv'
IN_ARCH_LABELS      = 'local_data/res/astro/17.labels_all_ages.parquet'   # all-age Arch1-4
```

**Outputs**:
```
OUT_ALL_AGES_TSV    = 'local_data/res/astro/36.all_ages_xp.tsv'
OUT_ALL_AGES_HTML   = 'local_data/fig/astro/36.all_ages_scatter.html'
```

**Projection chain** (four matrix ops, all postnatal cells at once):
```python
# 1. Outer PCA (fitted on P56)
pca_scores = (xn - pca_mean) @ pca_comps.T        # (n, N_PCS)
# 2. Varimax rotation
vx_all     = pca_scores @ varimax_R                # (n, N_PCS)
# 3. Subset to informative VX columns
vx_sub     = vx_all[:, vx_col_indices]             # (n, n_vx_cols)
# 4. Inner PCA (fitted inside SCA on P56 VX subspace)
xp_all     = (vx_sub - inner_mean) @ inner_comps.T # (n, NDIM)
```

**Normalization**: Use the same `norm()` call on ALL postnatal cells jointly (identical to script 33), so the global zscore reference is consistent.

**Visualization**: `scatter_categorical_html()` with `age` and `archetype` (from `17.labels_all_ages.parquet`) as metadata, archetype vertices overlaid.
