# Plan: Cross-Dataset Astrocyte Integration — Harmony + 10 PCs (Scripts 22 & 23)

## Context
Scripts 17/18 computed archetype labels for gao25 postnatal astrocytes (P56 reference, label relay to younger ages within the same dataset). The next step integrates two external datasets — cheng22 (P28, P38) and yoo25 (P21) — by transferring P56 archetype labels into a shared embedding space. This version uses harmonypy batch correction after PCA projection (before kNN), 10 PCA components, and retains all PCs (no PC2 drop), improving cross-dataset label transfer by removing dataset-level batch effects.

Labels source: `local_data/res/astro/17.labels_P56.parquet` (columns: PC1, PC3, PC4, PC5, donor_name, age, archetype)

---

## Key Challenge: Different Gene Sets
- gao25: 32,285 genes; cheng22/yoo25: 16,572 genes (a shared subset)
- Must intersect gene sets, reselect HVG from common genes, refit PCA on gao25 P56 cells

---

## Script 22: `22.cross_dataset_integration.py`

### File Paths (top of script, capitalized)
```
INPUT_GAO25       = links/astro/gao25_scrna_astro.h5ad
INPUT_CHENG22     = links/astro/cheng22_astro.h5ad

PARQUET_COMBINED  = local_data/res/astro/22.combined_labels.parquet
PARQUET_VERTICES  = local_data/res/astro/22.archetype_vertices.parquet
```

### Parameters
```python
N_TOP_GENES  = 2000
NDIM_PCA     = 10           # 10 components; all retained (no DROP_PCS)
K_NEIGHBORS  = 15
CHENG22_AGES = ['P28', 'P28_dr', 'P38', 'P38_dr']
YOO25_AGES   = ['P21', 'P21DR']
```

### Steps

1. **Load reference (gao25 P56)**
   - Filter to `Age == 'P56'`; load `17.labels_P56.parquet`; verify count match

2. **Load target datasets**
   - cheng22: filter to `CHENG22_AGES`; fail if any age missing
   - yoo25: filter to `YOO25_AGES`; fail if any age missing

3. **Find common genes + HVG selection**
   - Intersect all three datasets (full gao25); subset all to common genes
   - `select_hvg()` from `scripts/common.py` on gao25 P56 (common genes only)

4. **Normalize** (`norm()` from `scomics.utils`)
   - Independently per dataset: CP10k → log2(1+x) → z-score per gene

5. **Fit PCA on P56, project all**
   ```python
   pca = PCA(n_components=NDIM_PCA)
   pca.fit(xn_p56)
   xp_p56_raw     = pca.transform(xn_p56)
   xp_cheng22_raw = pca.transform(xn_cheng22)
   xp_yoo25_raw   = pca.transform(xn_yoo25)
   pc_cols = [f'PC{i+1}' for i in range(NDIM_PCA)]   # PC1..PC10
   ```

6. **Harmony batch correction**
   ```python
   import harmonypy as hm
   xp_all_raw   = np.vstack([xp_p56_raw, xp_cheng22_raw, xp_yoo25_raw])
   batch_labels = ['gao25'] * n_p56 + ['cheng22'] * n_cheng22 + ['yoo25'] * n_yoo25
   meta_df      = pd.DataFrame({'batch': batch_labels})
   ho           = hm.run_harmony(xp_all_raw, meta_df, 'batch', random_state=42)
   xp_all_h     = ho.Z_corr            # harmonypy 2.x returns (ncells, ndim) directly
   xp_p56       = xp_all_h[:n_p56]
   xp_cheng22   = xp_all_h[n_p56 : n_p56 + n_cheng22]
   xp_yoo25     = xp_all_h[n_p56 + n_cheng22:]
   ```

7. **kNN label transfer** (on harmony-corrected embeddings)
   ```python
   knn = KNeighborsClassifier(n_neighbors=K_NEIGHBORS)
   knn.fit(xp_p56, arch_labels_p56)
   labels_cheng22 = knn.predict(xp_cheng22)
   labels_yoo25   = knn.predict(xp_yoo25)
   ```

8. **Joint UMAP** on `xp_all_h`

9. **Archetype centroid vertices** — mean of `xp_p56` rows per archetype label (harmony-corrected)

10. **Save combined parquet**
    - Columns: `PC1..PC10, UMAP1, UMAP2, dataset, age, donor_name, cell_type, archetype`
    - `donor_name`: gao25 from `obs['donor_name']`; cheng22/yoo25 from `obs['Sample']`
    - `cell_type`: gao25 gets `''`; cheng22/yoo25 from `obs['Type']`
