# Plan: Script 38 — Variance Partitioning for cheng22 NR PCA + VX

## Context

Script 37 (`scripts/astro/37.embed_cheng22_nr.py`) embeds cheng22 P28+P38 NR astrocytes via PCA → varimax → UMAP → Leiden and saves `local_data/res/astro/37.cheng22_nr.h5ad`. It does not compute variance partitioning or top-gene tables. Script 38 picks up where 37 left off and produces the same analytical outputs that script 33.3 produces for P28 gray-matter cells: R² variance partitioning by archetype / donor / library_size for both PC and VX components, stacked bar charts, and top-genes-by-loading HTML tables.

### 2. New script 38

**File:** `scripts/astro/38.variance_partition_cheng22_nr.py`

**Reads:**
- `local_data/res/astro/37.cheng22_nr.h5ad`

**Outputs:**
- `local_data/res/astro/38.pca_variance_partition.tsv`
- `local_data/res/astro/38.vx_variance_partition.tsv`
- `local_data/fig/astro/38.variance_partition.html`

**Logic (mirrors 33.3 exactly):**

1. Load `37.cheng22_nr.h5ad`:
   - PCA scores: `adata.obsm['X_pca']`  → shape (n_cells, N_PCS)
   - VX scores: `adata.obsm['X_vx']`   → shape (n_cells, N_PCS)
   - PCA loadings: `adata.varm['PCA_loadings']`  → (n_hvg, N_PCS); transpose to get L for top-gene lookup
   - VX loadings: `adata.varm['VX_loadings']`    → (n_hvg, N_PCS)
   - Gene names: `adata.var_names`
   - Covariates: `adata.obs['archetype']`, `adata.obs['Sample']`, `adata.obs['depth']`

2. Build covariate matrices:
   - `X_arch = pd.get_dummies(archetype).values`
   - `X_donor = pd.get_dummies(sample).values`
   - `X_libsize = zscore(depth).reshape(-1, 1)`
   - `X_full = hstack([X_arch, X_donor, X_libsize])`

3. Reuse the same `r2()` helper (inline copy, same as 33.3):
   ```python
   def r2(X, y):
       reg = LinearRegression().fit(X, y)
       ss_res = np.sum((y - reg.predict(X)) ** 2)
       ss_tot = np.sum((y - y.mean()) ** 2)
       return 1 - ss_res / ss_tot
   ```

4. Compute partial R² for each PC and each VX component (same loop as 33.3):
   - factors: `archetype`, `donor`, `library_size`
   - residual: `max(1 - r2_full, 0)`
   - Save as TSV

5. Generate HTML (same plotly stacked bar + top-genes table as 33.3):
   - `COLORS` dict: archetype=#4C72B0, donor=#DD8452, library_size=#C44E52, residual=#CCCCCC
   - PCA bar chart with PCA variance fraction in x-axis labels (compute from scores variance, since `explained_variance_` isn't stored — use `pca_scores.var(axis=0)`)
   - VX bar chart with VX variance fraction in x-axis labels
   - Top-5-genes-by-|loading| HTML table for PCs and VXs
   - All concatenated into single HTML file

---

## Key Design Decisions

- Script 38 reads only from 37.h5ad (no re-reading original input h5ad) — requires the one-line patch to script 37 to persist `depth` in obs.
- Variance fraction for PCA x-axis labels: derived from `pca_scores.var(axis=0) / pca_scores.var(axis=0).sum()` (proportional to explained variance but computed from stored scores since `explained_variance_` is not saved in the h5ad).
- N_PCS inferred from `X_pca.shape[1]`; N_TOP_GENES=5 as in 33.3.
