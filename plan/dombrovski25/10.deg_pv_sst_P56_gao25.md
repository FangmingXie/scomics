# Plan: DEG Analysis — Pvalb vs Sst at P56 (Gao25 DevVIS, outgroup comparison)

## Context

Create a DEG script comparing Pvalb Gaba vs Sst Gaba inhibitory neurons at P56 in the Gao25 DevVIS mouse scRNA dataset. This serves as an outgroup comparison for the Dombrovski25 fly analysis, so the plan and script live under the `dombrovski25/` folder hierarchy. The script mirrors `scripts/dombrovski25/08.deg_pc2_bins_APF48h.py` but adapts for a different dataset and group definition.

## Dataset facts (DevVIS_scRNA_processed.h5ad)

- **Input**: `links/broad/DevVIS_scRNA_processed.h5ad` (568,654 × 32,285, sparse float32)
- **X content**: raw integer counts (all values are whole numbers, max=130) — same normalization path as fly dataset
- **Age filter**: `obs['Age'] == 'P56'` → 55,694 cells
- **Group A**: `subclass_label == 'Pvalb Gaba'` → ~1,041 P56 cells
- **Group B**: `subclass_label == 'Sst Gaba'` → ~1,121 P56 cells
- **MT prefix**: `'mt-'` (13 genes; mouse format vs `'mt:'` in fly)
- **Library depth**: no `nCount_RNA` column → compute as `np.array(adata.X.sum(axis=1)).flatten()`
- **Sparse X**: must call `.toarray()` before `np.array()`

## Output

- Script: `scripts/dombrovski25/10.deg_pv_sst_P56_gao25.py`
- Result: `local_data/res/dombrovski25_fly/10.deg_pv_sst_P56_gao25.parquet` (all genes, ranked by FDR)

## Implementation

### Header comment block
```
# DEG analysis: Pvalb Gaba vs Sst Gaba — P56 mouse VIS cortex, Gao 2025 DevVIS dataset
# Outgroup comparison for Dombrovski 2025 fly LPLC2 analysis
# Group A: Pvalb Gaba  vs  Group B: Sst Gaba
# Test: Wilcoxon rank-sum; Log2FC from CP10k+log2(1+x); FDR (BH) < 0.05 & |Log2FC| > 1
```

### File-path block (top of script)
```python
INPUT_FILE = os.path.join(PROJECT_ROOT, 'links', 'broad', 'DevVIS_scRNA_processed.h5ad')
RES_DIR    = os.path.join(PROJECT_ROOT, 'local_data', 'res', 'dombrovski25_fly')
OUT_DEG    = os.path.join(RES_DIR, '10.deg_pv_sst_P56_gao25.parquet')
```

### Parameters
```python
AGE           = 'P56'
GROUP_A_LABEL = 'Pvalb Gaba'
GROUP_B_LABEL = 'Sst Gaba'
FDR_THRESH    = 0.05
LOG2FC_THRESH = 1.0
```

### Key adaptations from template (08.deg_pc2_bins_APF48h.py)

| Aspect | Template (08) | New script (10) |
|--------|--------------|-----------------|
| Group source | PC2 bin parquet (IN_PCA) | `subclass_label` directly, no parquet needed |
| Cell filter | `type1 == CELLTYPE` + `orig.ident == AGE` | `Age == AGE` + split by `subclass_label` |
| MT prefix | `'mt:'` | `'mt-'` |
| Library depth | `adata.obs['nCount_RNA']` | `np.array(adata.X.sum(axis=1)).flatten()` |
| Dense X | `np.array(adata.X)` (already dense) | `adata.X.toarray()` then `np.array()` |

### Workflow (same as template)
1. Load h5ad → filter to `Age == 'P56'`
2. Remove mt- genes (`g.lower().startswith('mt-')`)
3. Compute depths from X.sum(axis=1); drop constant genes (var > 0)
4. CP10k + log2(1+x) normalization
5. Split Group A / Group B by `subclass_label`
6. Wilcoxon rank-sum per gene (`mannwhitneyu`, two-sided)
7. BH FDR correction (`multipletests`)
8. Assemble DataFrame with `gene, log2fc, pval, fdr, significant`; sort by FDR; save parquet
9. Print summary (n_sig, n_up, n_dn, top 10 by FDR)
