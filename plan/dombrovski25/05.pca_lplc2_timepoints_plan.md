# Plan: PCA Analysis of LPLC2 Cells by Time Point

## Context
Analyze LPLC2 cells from `links/fly/dombrovski25_fly.h5ad`, separating APF_48h / APF_72h / APF_96h. For each time point: PC1-PC2 scatter colored by sample metadata, and PC1-PC2 scatter colored by top PC1 gene expression.

## Script
`scripts/dombrovski25/05.pca_lplc2_timepoints.py`

## Pipeline
1. Load h5ad, filter to `type1 == 'LPLC2'`
2. `select_hvg()` on all LPLC2 cells (N_TOP_GENES=2000, consistent gene set)
3. Per time point (`orig.ident`):
   - Drop constant genes within subset
   - `norm()` → CP10k + log2(1+x) + z-score per gene
   - `sklearn.PCA(n_components=20)`
   - `scatter_2d_categorical_html([xp], cell_meta, ...)` — metadata dropdown
   - Top 20 genes by `|PC1 loading|` → `gene_expr_scatter_html(...)` — gene dropdown

## Outputs (`local_data/fig/dombrovski25_fly/`)
- `05.lplc2_{age}_pca_metadata.html` × 3
- `05.lplc2_{age}_pca_genes.html` × 3
