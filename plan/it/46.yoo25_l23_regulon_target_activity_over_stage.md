# Plan: L2/3 regulon-target activity across postnatal stages (Yoo25 AllAges)

## Context
We want to visualize how a regulon's activity changes over postnatal development in
L2/3 cortical excitatory neurons. The original plan (`plan/it/46.gao25_...md`) targeted the
gao25 DevVIS mouse dataset. The user has now directed us to use the **actual Yoo25 AllAges**
dataset (`links/it/superdupermegaRNA_yoo25_IT_AllAges.h5ad`), which has a real postnatal age
axis (P6→P21) for L2/3 IT neurons. This changes the input, the L2/3 subset label, the
normalization source, and the stage range. Headline output: a line plot of the **Fosb**
regulon activity across postnatal stages, with a separate overlaid line for the
**dark-reared (DR)** condition.

Because the dataset changes from gao25 to yoo25, the script/plan is **renamed**
`46.yoo25_l23_regulon_target_activity_over_stage` (was `46.gao25_...`).

## Inputs (verified by inspection)
- **Expression**: `links/it/superdupermegaRNA_yoo25_IT_AllAges.h5ad` — 89,287 IT cells × 16,572 genes.
  - `.X` holds **log-normalized** float data (max ≈ 7.49), NOT raw counts.
  - `.raw.X` holds **raw integer counts** (max 3093, all integers), same 16,572 genes in the same
    order as `.var` (`Xkr4, Gm1992, …`). **Use `adata.raw` for the pseudobulk sum.**
  - `.obs['Subclass']` — L2/3 subset = `'L2/3'` (38,539 cells). (Not `subclass_label`.)
  - `.obs['Age']` — postnatal stage. Values: `P6, P8, P10, P12, P14, P17, P21` (normal-reared)
    and `P12DR, P14DR, P17DR, P21DR` (dark-reared). Format: `P<day>` optionally suffixed `DR`.
  - `.obs['Sample']` — biological replicates (P6a/b/c …) — **not used** (pseudobulk pools by Age).
  - Mouse gene casing (`Fosb`, `Xkr4`) — matches the regulon table.
- **Regulon → target table**: `local_data/res/it/40.yoo25_L2_3_regulon_targets.tsv`
  (cols `regulon, TF, regulation_direction, source, Gene`; 140 regulons).
  Fosb regulon key = `Fosb_+/+` (95 targets, `regulation_direction == '+/+'`).
  Use `Gene` names directly (mouse casing matches the h5ad).

## Regulon activity definition
1. **Subset** to L2/3 (`Subclass == 'L2/3'`).
2. **Counts source**: use `adata.raw.X` (raw integer counts) with `adata.raw.var_names` for gene indexing.
3. **Parse Age** into `(day, condition)`: `day = int` from the `P<day>` prefix; `condition = 'DR'`
   if the value ends with `DR`, else `'normal'`. Keep ALL ages present (P6…P21 + the four DR ages).
4. **Pseudobulk by Age**: pool ALL L2/3 cells sharing the same `Age` value and sum raw counts →
   gene × age matrix (11 pseudobulk columns; Samples/replicates ignored).
5. **Normalize per age**: CPM = counts / age_total × 1e6; expression = `np.log1p(CPM)` = log(1+CPM).
6. **Min-max scale each gene to [0,1] across ALL 11 age columns jointly** (normal + DR together,
   so both lines share one scale; genes with zero range contribute 0).
7. **Regulon activity per age** = mean of the [0,1]-normalized values over that regulon's target
   genes present in the dataset (intersection with `raw.var_names`; n used / 95 printed).

## Plotting
- One panel per regulon in a grid (default `SELECTED_REGULONS = ['Fosb']` → single panel).
- **Two overlaid lines per panel**:
  - `normal`: points at days 6, 8, 10, 12, 14, 17, 21.
  - `DR`: points at days 12, 14, 17, 21.
- X-axis = postnatal day (numeric positions at the actual days; tick labels `P6…P21`).
  Y-axis = regulon activity (mean of [0,1]-scaled target expression). Legend distinguishes
  normal vs DR.
- `plt.rcParams['pdf.fonttype'] = 42`, `matplotlib.use('Agg')` (mirrors script 49).
