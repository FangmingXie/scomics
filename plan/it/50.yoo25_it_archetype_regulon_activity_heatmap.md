# Plan: Generalize script 48 (L2/3 archetype × regulon heatmap) to L4, L5IT, L6IT

## Context
Script 48 (`48.yoo25_l23_archetype_regulon_activity_heatmap.py`) builds a P21-vs-P21DR
archetype × regulon-activity heatmap for **L2/3** IT: it splits each of the two P21 conditions
into L2/3 archetypes, pseudobulks the top-N purest cells per (age, archetype), and colors each
regulon's per-row-max-normalized activity. The user wants the same analysis for the other IT
subclasses — **L4, L5IT, L6IT** — each of which already has archetypes defined (scripts 33/35/36,
analogous to script 34 for L2/3). This exposes how the same TF/IEG regulons partition across
each subclass's archetypes and how dark-rearing perturbs that, subclass by subclass.

Key facts established during exploration (all verified against the data):
- **Archetypes per subclass** come from the same pipeline as L2/3, with subclass-specific marker
  files and **variable archetype count (NOC)**:
  - L4  → `33.follow.two_L4_archetype_markers.tsv`  (NOC=3)
  - L5IT→ `35.follow.two_L5IT_archetype_markers.tsv` (**NOC=2**)
  - L6IT→ `36.follow.two_L6IT_archetype_markers.tsv` (NOC=3)
  - (L2/3 reference: `34.follow.two_L23_archetype_markers.tsv`, NOC=3)
  Marker files share columns `gene, archetype, log2FC, pval, fdr, frac_in, frac_out`, with
  `archetype ∈ {archetype_1, archetype_2[, archetype_3]}`. Scoring recipe is identical to
  script 34 (log2 CP10k → per-gene 2/98 percentile clip → [0,1] → mean over markers).
- **Regulon target files are per-subclass** (SCENIC+ run separately per layer):
  `40.yoo25_L4_regulon_targets.tsv`, `40.yoo25_L5IT_regulon_targets.tsv`,
  `40.yoo25_L6IT_regulon_targets.tsv` (same schema as the L2/3 file used by script 48).
- **AllAges h5ad** `links/it/superdupermegaRNA_yoo25_IT_AllAges.h5ad` has exact Subclass strings
  `L2/3, L4, L5IT, L6IT`; `adata.raw` and `obs['total_counts']` present; ages include `P21`,`P21DR`.

## Decisions (confirmed with user)
1. **Regulon panel = shared common panel.** Script 48's 28-regulon L2/3 panel does not transfer
   (L4 21/28, L6IT 15/28, **L5IT 10/28** present as `+/+`). Use the **8 regulons present in every
   target subclass**, in this FIXED order (developmental TFs, then IEG/AP-1):
   `SELECTED_REGULONS = ['Rfx3','Satb2','Tcf4','Mef2c','Fosb','Junb','Egr1','Irf2']`
   — identical panel across L4/L5IT/L6IT → rows are directly comparable subclass-to-subclass.
   **No hierarchical clustering** (fixed shared order, unlike base 48; matches the comparability goal).
2. **Scope = L4, L5IT, L6IT only.** New standalone script **50** loops over these three; script 48
   remains the L2/3 version. One heatmap + one long TSV + one aux score TSV per subclass.
3. **`N_TOP_CELLS = 100`** for all subclasses. Feasible: smallest (age,archetype) group in the
   P21/P21DR pools is 134 (L6IT P21-arch1) and 203 (L5IT), both ≥ 100. Fail-fast if any group < 100.
4. **No archetype relabeling/reordering.** The L2/3 A→C'/B→B'/C→A' relabel is L2/3-specific; other
   subclasses keep plain `A, B, C` (and `A, B` for L5IT), in native `archetype_1..k` order.

## Design — parametrize script 48 into a per-subclass loop
Structure: a config block + a `run_subclass(cfg)` function that reproduces script 48's pipeline,
called once per subclass. Reuse script 48 verbatim wherever possible.

**Config block (capitalized, per CLAUDE.md):**
```python
AGES = ['P21', 'P21DR']
N_TOP_CELLS = 100
SELECTED_REGULONS = ['Rfx3','Satb2','Tcf4','Mef2c','Fosb','Junb','Egr1','Irf2']  # fixed order
SUBCLASSES = [
  dict(subclass='L4',   token='L4',   markers='33.follow.two_L4_archetype_markers.tsv',
       regulons='40.yoo25_L4_regulon_targets.tsv'),
  dict(subclass='L5IT', token='L5IT', markers='35.follow.two_L5IT_archetype_markers.tsv',
       regulons='40.yoo25_L5IT_regulon_targets.tsv'),
  dict(subclass='L6IT', token='L6IT', markers='36.follow.two_L6IT_archetype_markers.tsv',
       regulons='40.yoo25_L6IT_regulon_targets.tsv'),
]
DIRECTION='+/+'; DEPTH_COL='total_counts'; SCORE_PCTILE=(2,98); CP10K=1e4; CP_TARGET=1e6
CMAP='RdBu_r'
```

**Per-subclass algorithm (identical to script 48 except where noted):**
1. **Load once, subset per subclass**: read AllAges once; per subclass subset to
   `Subclass == cfg.subclass & Age ∈ AGES`. Use `adata.raw` counts; `depth = obs['total_counts']`
   (validate finite/>0).
2. **Regulon targets**: read `cfg.regulons`, filter `regulation_direction == '+/+'`, build
   `{tf: set(Gene)}` for the 8 `SELECTED_REGULONS`; fail-fast if any key missing (guaranteed present).
3. **NOC from marker file**: `arch_labels = sorted(unique markers['archetype'])`
   (`archetype_1..k`) → `NOC = len(arch_labels)`; `ARCH_NAMES = ['A','B','C'][:NOC]`.
   Fail-fast if any archetype's marker set is empty or absent from `raw.var_names`.
4. **Recompute scores** (replicates `34.follow...py:227-244`): per archetype k,
   `l2 = log2(counts/depth*1e4 + 1)` over that archetype's markers ∩ `raw.var_names`;
   per-gene 2/98 percentile clip over the pool → [0,1]; `score_k = clipped mean`. → `scores (n×NOC)`.
5. **Assign** `assigned = scores.argmax(1)` (disjoint).
6. **Columns** = `[(age, k) for age in AGES for k in range(NOC)]` (age-major, native A..k order):
   2×NOC columns. Per (age,k) take top `N_TOP_CELLS=100` by `score_k` among assigned cells,
   **sum raw counts**. Fail-fast if any group < 100; print n_assigned / n_used.
7. **Activity** (as script 48): CPM = counts/col_total×1e6 → `log1p`; min-max scale each gene to
   [0,1] jointly across that subclass's columns; per-regulon activity = mean over targets ∩
   `raw.var_names` (print n used/total). **Per-row max-normalize.** Rows stay in fixed
   `SELECTED_REGULONS` order (no clustering).
8. **Heatmap**: `imshow` 8 rows × (2·NOC) cols, `cmap='RdBu_r'`, `vmin=0, vmax=1`; thin white
   cell gridlines; **thin black divider** between the P21 and P21DR blocks (at `x = NOC-0.5`);
   two-line column labels (archetype `A..` on axis, bold `P21`/`P21DR` centered above each block);
   colorbar "regulon activity (per-row max-normalized)"; title names the subclass.
   `matplotlib.use('Agg')`, `plt.rcParams['pdf.fonttype']=42`.
9. Write long TSV + aux score TSV (aux flag column named `in_top100`).

## Conventions / reuse
- Mirror `scripts/it/48.yoo25_l23_archetype_regulon_activity_heatmap.py` for the whole activity
  pipeline, per-row max-norm, white gridlines + thin black condition divider, two-line labels,
  mpl config. The only structural changes: (a) subclass loop + per-subclass file config,
  (b) NOC inferred per subclass (2 or 3) so column count varies, (c) fixed 8-regulon shared panel
  with no clustering, (d) `N_TOP_CELLS=100`, (e) no archetype relabel/reorder.
- Scoring recipe reference: `scripts/it/34.follow.two_L23_archetype_scores.py:227-244`.
- Standalone (no common.py); numpy/pandas/scipy.sparse/anndata/matplotlib (no scipy.cluster).
- **Fail-fast**: missing regulon key, empty target/marker ∩ var_names, non-finite/≤0 depth,
  any (age,archetype) group < N_TOP_CELLS, zero-count pseudobulk column.
