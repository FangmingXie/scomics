# Plan — script 52: dark-rearing response of archetype marker genes, all four IT subclasses

## Context

Scripts `50` and `51` already answer "how does dark-rearing shift expression within each L2/3
archetype?", but each does so for one hand-picked or enrichment-derived gene panel, and only for
L2/3. What is missing is the **self-referential** version across the whole IT sheet: for every
archetype, how does dark-rearing move *that archetype's own marker genes*, *inside that
archetype's own cells*?

That single number per (subclass, archetype) says whether dark-rearing pushes each archetype
further into its own identity or erodes it. Laid out left-to-right in laminar-depth order
(L2/3 A'B'C', L4 A'B'C', L5IT A'B', L6IT A'B'C') it becomes a readable 11-box summary of how
visual deprivation perturbs archetype identity across cortical depth.

New script: `scripts/it/52.yoo25_it_archetype_marker_p21dr_vs_p21_boxplot.py` (52 is the next
free number; the `plan/it/50.…md` that reused 50 was never implemented).

## What one box is (confirmed with the user)

For box `(subclass S, archetype k)`:

```
genes = markers(k)                     # k's OWN marker set only — the diagonal
cells = cells of S assigned to k       # argmax of recomputed archetype scores
1 point = 1 gene

log2FC_k(g) = log2( (CPM_P21DR[g, S, k] + 1) / (CPM_P21[g, S, k] + 1) )
```

Box sizes (= marker counts, deliberately unequal):

| | A' | B' | C' |
|---|---|---|---|
| L2/3 | 206 | 133 | 189 |
| L4 | 55 | 64 | 180 |
| L5IT | 135 | 159 | — |
| L6IT | 172 | 63 | 89 |

This is the diagonal of a (marker-set × archetype) grid — not full columns, and not per-replicate
points.

## Method (adapts scripts 50/51 — reuse their recipe verbatim where possible)

Reference implementation to mirror: `scripts/it/50.yoo25_l23_ieg_p21dr_vs_p21_foldchange.py`.
Steps 1–6 below are its lines 99–229 generalized over a subclass loop.

Per subclass `S` in `['L2/3', 'L4', 'L5IT', 'L6IT']`:

1. **Markers.** Read the subclass's marker TSV; `NOC = len(markers['archetype'].unique())` —
   infer it, do not hard-code 3 (L5IT has 2).
2. **Pool.** From `superdupermegaRNA_yoo25_IT_AllAges.h5ad`, subset
   `Subclass == S & Age in {'P21','P21DR'}`. Densify `adata.raw.X` (integer-valued counts) to
   float64. Depth is `obs['total_counts']`, validated finite and `> 0`.
3. **Recompute scores over the pooled P21+P21DR cells** (never read the saved
   `*_archetype_scores.tsv` — those contain no DR cells). Exact block from script 50:
   ```python
   l2 = np.log2(Xraw[:, cols] / depth[:, None] * 1e4 + 1.0)
   lo, hi = np.percentile(l2, (2, 98), axis=0)
   rng = np.where(hi > lo, hi - lo, 1.0)
   scores[:, k] = np.clip((l2 - lo) / rng, 0.0, 1.0).mean(axis=1)
   ```
4. **Assign** `scores.argmax(axis=1)` — disjoint.
5. **Pseudobulk** one column per `(age, archetype)`: among assigned cells take the top
   **`N_TOP_CELLS = 100`** by that archetype's score and **sum raw counts**. Fail-fast if any group
   has `< 100` assigned cells. (N=100 confirmed feasible: smallest group is 134, L6IT P21
   archetype_1; L5IT min 203, L4 min 447 — recorded in `plan/it/50.…md` and consistent with the
   P21/P21DR counts L2/3 2213/4256, L4 2173/3758, L5IT 424/787, L6IT 589/1129.)
6. **CPM-normalize each column** independently (`pb / col_totals * 1e6`), then per archetype `k`
   take `log2((cpm_P21DR + 1.0) / (cpm_P21 + 1.0))` **restricted to `markers(k)`**.

Normalization note to carry into the docstring: the fold change is taken on raw pseudobulk CPM,
deliberately *not* on the `[0,1]` min-max-scaled values used by 48.v2/49, so that `log2FC = 0`
means "unchanged by dark-rearing". `PSEUDO = 1.0` CPM stabilizes low-expression genes.

Fail-fast checks: every marker gene present in `raw.var_names` (verified: all 299/528/294/324
are); no zero-count pseudobulk column; arc-table/marker-file key agreement (above).

## Figure — upper panel

PDF, matplotlib (`Agg`, `pdf.fonttype = 42`, `svg.fonttype = 'none'`), following the
boxplot idiom of script 50 lines 243–262:

- 11 boxes in `arc_rank` order, `widths=0.6, showfliers=False, patch_artist=True`,
  `medianprops=dict(color='black', linewidth=1.4)`.
- Facecolor by **displayed** letter (`A'→C0, B'→C1, C'→C2`) at `alpha=0.55`.
- Deterministic jittered black points over each box —
  `jitter = (np.arange(n) - (n-1)/2) / n * 0.5`. **No RNG** (project constraint, stated in 50:250).
  With n up to 206, use a small marker (`s≈4, alpha≈0.4`) so boxes stay readable.
- Dashed grey `axhline(0)` — the "dark-rearing changes nothing" reference.
- Subclass grouping: thin vertical dividers between subclass blocks and a subclass label above
  each block, so the x-axis reads `A' B' C'` under `L2/3`, etc.
- Per-box `n` annotated under the tick label.
- `ylabel = 'log2(P21DR / P21)'`; `sns.despine` or manual top/right spine removal.

## Figure — lower panel (significant up/down counts)

A barplot sharing the x-axis: per archetype, the count of its own marker genes significantly moved
by dark-rearing, up drawn above zero (`#d62728`) and down below (`#1f77b4`), reusing the volcano
color convention of `scripts/viz.py:save_volcano_pdf`. Bars are a **strict decomposition of the box
directly above** — same genes, same cells, same fold changes — so dotted `±LOG2FC_THRESH` guides are
drawn on the upper panel to show the cut being counted. Counts annotated on each bar; y ticks
labelled as positive counts on both sides (the sign encodes direction, not a negative count).

Cuts: `FDR_THRESH = 0.05`, `LOG2FC_THRESH = 1.0`.

**Significance.** The pseudobulk has one column per (age, archetype), so it carries no replicate
structure and cannot itself yield a p-value. Significance is taken per cell: a two-sided Wilcoxon
rank-sum (`scipy.stats.mannwhitneyu`, axis-vectorized) on per-cell CP10k log2 expression, P21DR vs
P21, over the *same* top-`N_TOP_CELLS` cells that formed the pseudobulk columns, with BH-FDR
(`statsmodels.multipletests`) across that archetype's marker set. This matches how scripts 33–36
derive the marker sets themselves; the rank test is invariant to the CP10k/log2 transform. Running
the test on the same cells that produced the fold change is what makes the bars an exact subset of
the points above.

Layout: `plt.subplots(2, 1, sharex=True, height_ratios=[3.0, 1.5], hspace=0.08)`; x tick labels and
the bold subclass labels move to the lower panel; subclass dividers drawn on both.

`fig.savefig(OUT_PDF, bbox_inches='tight', dpi=300)`; `plt.close(fig)`. (No `tight_layout` — it
fights the shared-axis `hspace`.)
