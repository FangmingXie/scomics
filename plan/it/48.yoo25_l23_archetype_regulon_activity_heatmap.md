# Plan: P21 vs P21DR archetype × regulon-activity heatmap (Yoo25 AllAges)

## Context
Script 47 renders a regulon × postnatal-stage heatmap where each column is one Age
pseudobulk. The user wants a **new script** that (1) restricts to the two P21 conditions
(**P21** normal and **P21DR** dark-reared) and (2) splits each condition into the three L2/3
**archetypes A, B, C** — so each column becomes an (age, archetype) pseudobulk. This exposes
how the IEG/TF regulons differ *across archetypes* and how dark-rearing perturbs that,
directly on the same 13-regulon panel as script 47.

Archetypes were defined in **script 34** (`34.follow.two_L23_archetype_scores.py`): PCHA on a
cheng22-P28 + yoo25-P21 Harmony embedding, NOC=3, labels **A/B/C** ↔ `archetype_1/2/3`. Its
per-cell score is a **percentile-clipped (2/98) mean of each archetype's marker genes**
(markers saved in `34.follow.two_L23_archetype_markers.tsv`).

**Key constraint discovered:** script 34 scored only P21-normal + cheng22 cells — the saved
scores (`34.follow.two_L23_archetype_scores.tsv`) match 100% of AllAges L2/3 P21 cells but
contain **zero** P21DR cells. Therefore scores must be **recomputed** for both ages using
script 34's marker sets + identical method, so P21 and P21DR are on one footing.

## Decisions (confirmed with user)
- **Scores**: recompute per-cell A/B/C scores for the **joint P21 + P21DR L2/3 pool** from the
  script-34 marker gene sets, using the identical scoring recipe (log2 CP10k → per-gene 2/98
  percentile clip over the pool → [0,1] → mean over that archetype's markers).
- **Membership**: **argmax-assign** each cell to its highest-scoring archetype (disjoint sets),
  then take the **top N=300** cells by that archetype's score **within each (age, archetype)**.
- Feasibility verified — assigned-cell counts per group (all ≥ 300, so N=300 works):
  P21 A=352, B=1099, C=762 · P21DR A=1406, B=643, C=2207. All markers present
  (A 189/189, B 133/133, C 206/206). Pool = 6,469 cells (P21 2,213 + P21DR 4,256).

## Algorithm
1. **Regulon targets**: load, filter `regulation_direction == '+/+'`, build `{tf: set(Gene)}`
   for the 13 `SELECTED_REGULONS`; fail-fast if any key missing (mirrors script 47).
2. **Pool**: subset AllAges to `Subclass == 'L2/3'` AND `Age ∈ {'P21','P21DR'}` (6,469 cells).
   Use `adata.raw` for counts; `depth = obs['total_counts']`.
3. **Recompute scores** (replicates `34.follow...py:227-244`): for each archetype
   k∈{A,B,C}, markers = marker rows for `archetype_{k+1}` ∩ `raw.var_names`;
   `l2 = log2(counts/depth*1e4 + 1)`; `lo,hi = pctile(l2,[2,98],axis=0)`; scale to [0,1]
   (zero-range → /1); `score_k = clip(...).mean(axis=1)`. → `scores` (n_pool × 3).
4. **Assign**: `assigned = scores.argmax(axis=1)` → each cell to A/B/C (disjoint).
5. **Six pseudobulk columns** (age-major order `P21_A, P21_B, P21_C, P21DR_A, P21DR_B,
   P21DR_C`): for each (age, k), take cells with `Age==age & assigned==k`, pick the top
   `N_TOP_CELLS=300` by `score_k`, **sum raw counts** over them → gene vector. Fail-fast if a
   group has < 300 assigned cells; print n_assigned and n_used per column.
6. **Regulon activity** (mirrors script 47): CPM = counts/col_total×1e6 → `log1p`; **min-max
   scale each gene to [0,1] jointly across the 6 columns**; per regulon activity = mean over
   targets ∩ `raw.var_names` (print n used / total).
7. **Row display + order**: per-row **max-normalize** (each regulon / its own max across the 6
   cols; peak→1); **hierarchically cluster rows** (`correlation` dist, `average` linkage,
   `scipy.cluster.hierarchy.linkage`/`leaves_list`) for row order — all as in script 47.
8. **Heatmap**: `imshow` 13 rows × 6 cols, `cmap='RdBu_r'`, `vmin=0, vmax=1`; two-line column
   labels (`P21`/`A`…), a bold white divider between the P21 and P21DR triplets; white minor
   gridlines; colorbar "regulon activity (per-row max-normalized)". `matplotlib.use('Agg')`,
   `plt.rcParams['pdf.fonttype']=42`.
9. Write the long TSV and aux scores TSV.

## Conventions
- Capitalized path vars + config block at top: `SELECTED_REGULONS` (same 13 as script 47:
  Fos, Fosb, Fosl2, Egr1-4, Rfx3, Meis2, Nfib, Tcf12, Jdp2, Satb1), `DIRECTION='+/+'`,
  `SUBCLASS_COL='Subclass'`, `KEEP_SUBCLASS='L2/3'`, `AGE_COL='Age'`, `AGES=['P21','P21DR']`,
  `ARCH_MARKER_LABEL={'A':'archetype_1','B':'archetype_2','C':'archetype_3'}`,
  `N_TOP_CELLS=300`, `SCORE_PCTILE=(2,98)`, `DEPTH_COL='total_counts'`, `CP10K=1e4`,
  `CP_TARGET=1e6`, `CMAP='RdBu_r'`, `CLUSTER_METRIC='correlation'`, `CLUSTER_METHOD='average'`.
- Standalone (no common.py); numpy/pandas/scipy.sparse/scipy.cluster/anndata/matplotlib.
- **Fail-fast**: missing regulon key, empty target/marker intersection, non-finite/≤0 depth,
  any (age,archetype) group with < N_TOP_CELLS cells, zero-count pseudobulk column.
