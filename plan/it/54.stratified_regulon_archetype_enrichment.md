## Problem

`41.regulon_archetype_enrichment.py` scores each (archetype marker set `M_a`, regulon target set
`T_r`) pair with a one-sided Fisher exact test over a universe `U` of ~16.5k expressed genes. The
hypergeometric null assumes `M` and `T` are exchangeable draws from `U`. They are not — both are
strongly biased toward highly expressed genes — so `log2_or` is partly a function of a modelling
choice rather than of the data:

```
                          median shift when U goes 16544 -> 3795 genes
log2_or                   +1.590   (IQR [+1.58, +1.62])
```

A near-constant +1.6 offset. Since `41b`/`41c`/`41d` threshold on **absolute** values
(`STAR_LOG2OR = 3.0`, ramp `[0, 6.5]`), that offset silently sets how much of the figure lights up.

The confound is expression level, and it is almost entirely so — stratifying the L2/3 universe into
mean-expression deciles removes ~93% of the coupling between marker status and regulon-target status.
That is what this script exploits.

## Core result: the matched-background null is exact, not Monte Carlo

The plan was originally written around `B = 20000` resampled pseudo-marker sets. **That is
unnecessary.** Under bin-stratified resampling of the marker side, the null distribution has a
closed form.

Draw `M*` by sampling, within each expression stratum `b`, exactly `m_b = |M ∩ b|` genes uniformly
without replacement from the `n_b = |U ∩ b|` genes in that stratum, independently across strata.
Then with `t_b = |T ∩ b|`:

```
|M* ∩ T|  =  Σ_b |M*_b ∩ T|   where   |M*_b ∩ T| ~ Hypergeometric(n_b, t_b, m_b),  independent
```

So the null is a **convolution of per-stratum hypergeometrics**:

```
E[X]   = Σ_b  m_b t_b / n_b
Var[X] = Σ_b  m_b (t_b/n_b) (1 - t_b/n_b) (n_b - m_b) / (n_b - 1)
pmf    = conv_b  hypergeom.pmf(0..min(m_b,t_b);  n_b, t_b, m_b)
p      = Σ_{k >= x} pmf[k]                      (one-sided, exact)
```

Verified against brute-force resampling (L2/3, `Aff4_+/+` × archetype_1, |M|=189, |T|=25):

```
closed form   mean = 0.6479   sd = 0.7836    P(X>=3) = 0.02412
monte carlo   mean = 0.6542   sd = 0.7858    P(X>=3) = 0.02390    (B = 20000)
```

Consequences: exact tail probabilities with no `1/(B+1)` floor, deterministic and reproducible, no
seed, no draw-count parameter, and fast enough that the whole four-layer analysis is seconds.

**41's current test is the one-stratum special case** of this (`n_1 = N`, `m_1 = |M|`, `t_1 = |T|`
gives exactly `Hypergeometric(N, T, M)`, the Fisher null). So `54` is a strict generalisation, not a
different method — which makes the comparison between them clean and the diff easy to defend.

## Does it fix the universe problem? Yes — measured, not assumed

Same 417 L2/3 pairs, statistic recomputed under both universes:

```
                median shift       IQR of shift      spearman(full, target-union)
log2_or            +1.590        [+1.58, +1.62]           0.9994
log2_enr           +0.199        [+0.12, +0.25]           0.9968
```

**8× more stable.** The mechanism is analytic, not luck: `E[X] = Σ_{g∈T} (local marker density at
g's expression level)`. Adding 12k low-expression genes to `U` adds them to strata where
`m_b/n_b ≈ 0`, so they contribute ~0 to both the observed overlap and the expectation. Genes outside
the marker-eligible expression range simply drop out of the arithmetic instead of inflating `N`.

## Specification

Per layer, per (archetype `a`, regulon `r`):

```
x         = |M_a ∩ T_r|
strata    = N_BINS quantile bins of mean log2-CP10k expression over U
exp       = Σ_b m_b t_b / n_b                      (matched-background expectation)
log2_enr  = log2((x + 0.5) / (exp + 0.5))          PRIMARY effect size, replaces log2_or
z         = (x - exp) / sqrt(Var)                  reported, not thresholded on (counts are small)
p_strat   = exact upper tail of the convolved pmf at x
p_mid     = p_strat - 0.5 * pmf[x]                 mid-p, see "Discreteness" below
fdr       = BH over all (a, r) pairs within a layer, on p_mid
```

`log2_enr` is on the same scale as `log2_or` for rare sets (both approximate `log2(obs/exp)` when
`|M|,|T| << N`), so the existing colour ramp is roughly transferable — but see "Downstream" below.

### Design parameters — all shown to be non-critical

Median `log2(obs/exp)` over all 417 L2/3 pairs, by stratification scheme:

```
1 stratum (= 41 Fisher today)      +0.438     IQR [-0.52, +1.90]
10 strata, mean expression         -0.205     IQR [-0.98, +0.91]
20 strata, mean expression         -0.226     IQR [-1.02, +0.81]
40 strata, mean expression         -0.238     IQR [-1.01, +0.78]
20 strata, detection rate          -0.192     IQR [-0.96, +0.92]
20 strata, variance                -0.275     IQR [-1.08, +0.67]
```

The current test carries a **+0.438 systematic inflation**; every stratified variant removes it, and
they agree with each other to within 0.08. So:

- `N_BINS = 20`, **mean log2-CP10k expression**. Defensible default; the result does not hinge on it.
- Bin by `rank(method='first')` before `qcut` — raw expression has heavy ties at the low end and
  `qcut` on tied values produces unequal, sometimes empty bins.
- **Do not build the 2-D (expression × variance) stratification.** Attempted in the prototype and it
  produces empty strata (`nb = 0` → NaN) because expression and variance are strongly correlated, and
  it buys nothing over 1-D (−0.275 vs −0.226). Record it as rejected, with the reason.
- Report the 10/20/40-bin sensitivity as a validation output, not as a tunable.

The residual −0.2 median is a **pseudocount artefact, not over-correction**: 46.3% of pairs have
`x = 0`, where `log2((0+0.5)/(exp+0.5))` is necessarily negative for `exp < 0.5`. Assess calibration
on p-values, not on the smoothed ratio.

### Discreteness — the one real statistical wrinkle

```
pairs with x = 0 : 193 of 417 (46.3%)   -> exact one-sided p = 1.0 exactly
pairs with x <= 2: 284 of 417 (68.1%)
```

Nearly half the tests have a point mass at `p = 1`, which makes BH conservative and distorts any
uniformity check. Two required responses:

1. Use **mid-p** (`p_strat - 0.5 * pmf[x]`) as the BH input. Standard for discrete tests, restores
   approximate uniformity under the null. Keep the exact `p_strat` in the output too — mid-p is not a
   valid p-value in the strict sense and should not be the only number recorded.
2. When reporting calibration, state the fraction at `x = 0` alongside it. Observed
   `frac(p <= 0.05) = 0.185` is *not* evidence of miscalibration — a real signal is expected — but it
   is uninterpretable without the discreteness figure next to it.

## Implementation

```
scripts/it/54.stratified_regulon_archetype_enrichment.py
```

Originally drafted as `41e`, inside the 41 family, on the grounds that it recomputes the same
statistic on the same inputs and its output is a drop-in for `41b`/`41c`/`41d`. It outgrew that: the
set is now five scripts, so it takes its own number with lettered derivatives (`54b`–`54e`), mirroring
how `41`/`41b`/`41c`/`41d` is organised. The output schema stays a superset of 41's, so the drop-in
property is unchanged.

Structure, mirroring `41.enrich_layer`:

```python
for cfg in m41.LAYERS:
    universe, stats = m41.reconstruct_gene_universe(coords.index, cfg['subclass_val'], adatas)
    bins = pd.qcut(stats['mean'].rank(method='first'), N_BINS, labels=False).values
    nb   = np.bincount(bins, minlength=N_BINS)
    for a in archetypes:
        mb = np.bincount(bins[M_idx[a]], minlength=N_BINS)
        for r in regulons:
            tb = np.bincount(bins[T_idx[r]], minlength=N_BINS)
            ...  # closed-form mean/var + convolved pmf
```

Complexity: convolution support is bounded by `min(|M|, |T|) <= 206`, over 20 strata, for ~1700
pairs across four layers. Sub-second per layer. **No Monte Carlo, no seed, no `B` parameter.**

Numerical care (fail-fast, per CLAUDE.md):

- `float64` throughout; `assert abs(pmf.sum() - 1) < 1e-9` after each convolution — repeated
  convolution is where silent mass loss would show up.
- `assert (nb > 0).all()` after binning; an empty stratum means the binning is wrong, so raise rather
  than mask with `np.maximum(nb, 1)`.
- `assert (mb <= nb).all() and (tb <= nb).all()`.
- Skip strata with `m_b == 0 or t_b == 0` — they contribute a point mass at 0 and convolving them is
  a no-op, but skipping is cheaper and keeps the pmf short.

## Downstream — do not change yet

`41b`/`41c`/`41d` currently threshold `log2_or > 3.0`, `FDR < 0.05`, `overlap >= 5`, ramp `[0, 6.5]`.
`log2_enr` compresses the top end (max ~3.5 vs ~6.4 for `log2_or`), so `STAR_LOG2OR = 3.0` is far too
high on the new scale and the ramp must be rescaled. `41c`'s row *selection* would also change, which
changes the row set of every downstream figure.

Do not touch them in this script. Produce `54`'s outputs and the validation table first, then decide
with the user. `MASK_MIN_OVERLAP = 5` stays regardless — it is the one criterion no universe or null
choice can inflate, and the demotion table above shows it is already absorbing most of the damage.

## Rejected alternatives (recorded so they are not re-litigated)

- **Monte Carlo resampling with `B` draws** — superseded by the exact convolution. Retained only as a
  unit test.
- **2-D expression × variance strata** — produces empty strata; no measurable benefit over 1-D.
- **Randomising the regulon side instead of the marker side** — unnecessary. `M*` carries `M`'s
  expression profile, so `E[|M* ∩ T|]` already absorbs whatever expression bias `T` has, and the
  marker side is the cheap direction (11 archetypes vs 349 regulons, and strata are reused across all
  regulons in a layer).
- **Logistic-regression marker propensity + Poisson-binomial null** — avoids bin-edge arbitrariness,
  but requires a smoothness assumption and does not preserve `|M*| = |M|`. The bin-count sensitivity
  above shows the arbitrariness it would fix is worth < 0.05 in `log2_enr`.
