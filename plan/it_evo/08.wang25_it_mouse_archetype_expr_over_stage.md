# Mouse IT archetype programs over human developmental stage (wang25 multiome)

## Context

`scripts/l23_evo/50.viz.wang25_multiome_l23_ap1_egr_regulon_target_expr_over_stage.py` tracks
AP-1/EGR **regulon-target** activity across developmental stage in human L2/3 IT neurons of the
Wang25 developing-cortex 10x multiome GEX dataset.

We want the same temporal readout, but for the **mouse IT archetype programs** defined in
`scripts/it/` — L2/3 A/B/C, L4 A/B/C, L5 IT A/B, L6 IT A/B/C — asking when during human
development each archetype's transcriptional program emerges. Mouse markers are mapped to human
orthologs (same approach as `scripts/l23_evo/60.mouse_abc_scores_on_human_cells.py`), then scored
in the matching human IT type.

This is a cross-layer, cross-species question, so it belongs in the `it_evo` sub-project rather
than `l23_evo`. Next free number there is **25**.

## Decisions

- **Scope**: all four IT layers → needs the all-IT wang25 file (not previously symlinked).
- **Region**: **V1 only**, matching script 50.
- **Y-scaling**: two rows — raw score (row 1) and per-archetype min-max across stages (row 2).

### Structure

Config block:

### Ortholog map (mirror `60.mouse_abc_scores_on_human_cells.py:57-63`)

```python
ortho = pd.read_csv(IN_ORTHOLOGS, sep='\t')
ortho = ortho.drop_duplicates('human_symbol').drop_duplicates('mouse_symbol')
mouse_to_human = dict(zip(ortho['mouse_symbol'], ortho['human_symbol']))
```
Then per archetype: mouse markers → human symbol → keep those present in `adata.var_names`.

### Per-panel computation

1. Subset once: `adata[(Type == human_type) & (Region == KEEP_REGION)]`. Raise if empty.
2. Densify that subset only (largest is EN-L4-IT V1, 11,834 cells — fine), `float64`,
   `depth = X.sum(1)`; raise on any zero-depth cell.
3. Per archetype, reuse script 50's scoring verbatim (generalize `regulon_stage_stats` into
   `archetype_stage_stats(genes, X, depth, stage, stages)`):
   `log2(count/depth*1e4 + 1)` → per-gene min–max over `NORM_PCTILE` percentiles **within this
   panel's cells** → clip [0,1] → mean across genes → per-cell score.
4. Per-stage `n_cells`, `mean`, `std`, `sem`; then `mean_norm`/`sem_norm` = min–max of the
   per-stage means (same as script 50, raising if the range is 0).

Normalization is computed inside each layer's own cell subset, so each panel is self-contained.

### Figure

2 rows × 4 columns, `figsize=(4.2*4, 7.0)`.
- Row 1: raw `mean` ± `sem`, per-panel autoscaled y (gene sets differ between layers, so no
  `sharey` across panels). Ylabel on col 0: `mouse archetype score\n(per-gene [0,1] mean)`.
- Row 2: `mean_norm` ± `sem_norm`, `sharey=True` across the row (naturally [0,1]).
  Ylabel on col 0: `min-max normalized across stages`.
- One color/marker per archetype letter (index into `LINE_COLORS`/`LINE_MARKERS`), legend
  `A (n genes)` per panel; x tick labels only on row 2, rotated 45°, with per-stage `n` appended
  (e.g. `Second trimester\n(n=38)`); `set_xlim(-0.4, len(stages)-0.6)`; top/right spines off.
- Column titles `{label} — {human_type}` on row 1; suptitle
  `Mouse IT archetype programs over human developmental stage — Wang25 multiome (V1)`.

### Output TSV

Long format, one row per (panel, archetype, stage):
`panel, human_type, archetype, arch_id, n_markers_mouse, n_genes_used, stage, n_cells, mean, std, sem, mean_norm, sem_norm`

### Fail-fast (per CLAUDE.md — no silent fallbacks)

- Unknown `Group` value not in `STAGE_ORDER` → `ValueError`.
- Zero cells for a `(Type, Region)` combination → `ValueError`.
- An archetype with zero ortholog-mapped genes present in the data → `ValueError`
  (do not skip the line).
- Flat per-stage means (min–max range 0) → `ValueError`, as in script 50.

## Known caveat to surface in output

V1-only second-trimester bins are thin: L2/3 **38**, L4 **55**, L5 **117**, L6 **1085** cells
(third trimester: 108 / 445 / 290 / 92). Error bars at the two fetal stages will be wide and the
L6 third-trimester point rests on 92 cells. This is why `n_cells` goes into the TSV and the tick
labels — no stage is silently dropped. If the fetal end looks too noisy to interpret, the
PFC+V1 pooled version is a one-line change (`KEEP_REGION`) that raises those counts to
66 / 127 / 187 / 3137.
