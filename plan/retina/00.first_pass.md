# Plan: First-pass Xenium retina analysis

## Context
Standard single-cell pipeline on the Xenium mouse retina trial dataset
(`links/retina/trial/`). The slide has multiple tissue sections; the
upper-right corner (x ≥ 5500, y ≤ 2500 in image coordinates) is selected for
analysis. Uses the project's custom pipeline (h5py → scipy.sparse → sklearn
PCA → UMAP → KMeans) because scanpy has a metaclass conflict in the `archetype`
environment.

## Script
`scripts/retina/00.first_pass_xenium_trial.py`

## Pipeline

1. **Load** `cell_feature_matrix.h5` (Gene Expression features only, 5 006 genes)
   + `cells.parquet` (spatial coords, count breakdown, segmentation metadata)
2. **Spatial overview** — subsample 50k cells, plotly scatter showing all sections
   with section-filter region highlighted
3. **Section filter** — x ≥ SECTION_X_MIN, y ≤ SECTION_Y_MAX
4. **QC metrics** — compute `n_genes_by_counts`, use `total_counts` from parquet,
   compute `fdr = 1 − transcript_counts / total_counts`
5. **QC figures** (all plotly html):
   - Spatial QC (3-panel: total_counts / n_genes / fdr)
   - Violin plots (n_genes, total_counts, fdr)
   - cell_area vs n_genes, colored by segmentation_method
   - nucleus_area vs cell_area, continuous color by nucleus_count
   - FDR histogram with MAX_FDR threshold line
6. **Filter** — MIN_COUNTS, MIN_GENES, MAX_FDR
7. **HVG → norm → PCA → UMAP → KMeans** using `common.select_hvg`,
   `scomics.utils.norm`, sklearn PCA, umap-learn UMAP, sklearn KMeans
8. **Save** `local_data/res/retina/00.first_pass.h5ad`
9. **UMAP figures**:
   - KMeans clusters (via `viz.scatter_2d_categorical_html`)
   - QC metrics dropdown (total_counts, n_genes, fdr via same function)
